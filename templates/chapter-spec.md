## 개념 절 제목

- **핵심 메시지:** 이 절을 읽고 남아야 할 한 문장
- **설명 순서:** 왜 필요한가 / 정의 / 직관 / 수식 / 코드 / 연구에서의 의미 — 쓸 단계와 요점만
- **예제:** 공통 예제(실 1 진동자 · 실 2 열 방정식 · 실 3 실제 데이터) 또는 절 고유 예제
- **시각화·위젯:** 그림 설명 또는 `위젯 이름`(프리셋), 사용할 효과
- **코드:** 코드 셀의 목적, `exec` 수준(browser · python · gpu)
- **예측 퀴즈:** 절 앞에 놓을 질문 / 흔한 오답
- **흔한 오개념:** 실패 사례로 연결할 착각
- **참고:** 근거 문헌(원문 확인한 것)
