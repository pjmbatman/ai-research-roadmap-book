# UI/UX 설계

> 상태: **채택** ([ADR 0012](decisions/0012-bento-quest-lab.md), 2026-11-07).
> 관련 문서: 시각 토큰과 화면 구조는 [design-system.md](design-system.md), 레퍼런스 조사는 [benchmarks.md](benchmarks.md), 시스템 구조는 [platform-architecture.md](platform-architecture.md).

## 1. 이 서비스의 UX가 풀어야 할 문제

1. **분량이 크고 순서가 하나가 아니다.** 215개 장을 처음부터 읽는 독자는 없다. 그래서 로드맵이 전체 내비게이션이고, 메인은 "지금 이어서 할 것"을 가장 크게 보인다.
2. **읽는 책이 아니라 훈련하는 서비스다.** 장은 퀘스트처럼 노드를 하나씩 마치고, 퀴즈와 실습을 지나 통과 기준에서 끝난다.
3. **이론과 실습이 끊기지 않아야 한다.** 위젯과 코드 셀은 수업 시트의 한 쪽으로 들어가 있다. 연습문제는 같은 장의 실습실에서 바로 채점된다.

## 2. 정보 구조

```
위 막대: 로고 · 홈 · 로드맵 · 트랙 · 내 진도 · 검색(⌘K) · 테마
메인 /                        Bento: 이어서 학습 → 퀘스트, 실습실 타일 → 실습실
 ├─ 지도 /map/                레이어 × 트랙 의존 관계
 ├─ 트랙 /tracks/<key>/       그 트랙의 로드맵: 부(주제) → 장(하위 주제), 노드 서랍
 │   └─ 장 /<부>/<장>/         본문이 있으면 퀘스트, 없으면 '다룰 내용' 카드
 │       └─ 실습실 /<부>/<장>/lab/   연습문제가 있는 장만
 ├─ 부 /<부>/                  장 목록
 └─ 내 진도 /progress/         숫자 카드 · 트랙별 진행 · 내보내기·가져오기
```

## 3. 한 장을 배우는 흐름

1. **메인**에서 이어서 학습 타일을 누른다. 타일이 커지며 퀘스트로 넘어간다.
2. **퀘스트**에서 말풍선이 붙은 "지금 할 노드"를 누른다.
   - 읽기 노드: 수업 시트에서 한 쪽씩 넘기고 "완료"를 누른다.
   - 퀴즈 노드: 맞히면 끝난다.
   - 노드를 마치면 초록으로 바뀌고 길이 이어진다. 구간을 다 마치면 다음 구간 탭으로 넘어간다.
3. **실습실 노드**를 누르면 화면이 어두워지며 실습실이 부팅된다.
   - 편집기에서 `submission.py`를 고치고 채점한다. 터미널에서 `python`·`check`로 돌려 볼 수도 있다.
   - 모두 통과하면 "퀘스트로 돌아가기"가 나온다.
4. **통과 기준**에서 퀴즈 · 연습문제 · 자기 점검이 모두 채워지면 "장 완료"를 누른다. 그다음 "다음 장"으로 간다.

## 4. 진도 모델 (roadmap.sh)

장마다 상태가 넷이다: 시작 전 · 학습 중 · 완료 · 건너뜀.
- **자동:** 장을 열면 학습 중이 된다. 퀴즈·연습문제·통과 기준 체크를 모두 마치면 완료가 된다.
- **수동:** 로드맵 노드 서랍에서 상태를 직접 고를 수 있다. 수동 선택이 자동 판정보다 우선한다.
- **퀘스트 노드:**
  - 읽기 노드는 `steps`에 기록한다.
  - 퀴즈 노드는 그 문항을 맞혔는지, 실습실 노드는 연습문제를 모두 통과했는지로 판정한다.
  - 통과 기준은 "장 완료"를 눌렀는지로 판정한다.
- **저장:** 브라우저 localStorage의 `roadmap:progress:v1`에 장 id를 키로 저장한다.

## 5. 학습 원칙 (화면과 무관하게 유지)

- **예측 → 관찰 → 설명.** 개념 다음에 확인 퀴즈를 두고, 위젯과 코드로 확인한 뒤 해설한다.
- **순서는 안내하되 잠그지 않는다.** 참조로 찾아 읽는 독자를 위해 모든 노드를 열어 둔다.
- **Python은 필요할 때 내려받는다.** 코드 셀은 실행할 때, 실습실은 들어갈 때 Pyodide를 불러온다. 기다리는 동안 화면 맨 위 로딩 막대와 실습실의 상태 표시가 보인다.
- **접근성.**
  - 모든 조작은 키보드로 가능하다: 시트는 ←→·Enter·Esc, 터미널은 ↑↓·Tab.
  - `prefers-reduced-motion`이면 전환 애니메이션을 끈다.
