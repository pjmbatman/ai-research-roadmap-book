# 문체·용어·표기 가이드

## 1. 독자와 목소리

- **독자:** AI를 배우는 과학자·공학자와 과학 문제로 넘어오는 AI 연구자, 그리고 학부·대학원 입문자. 똑똑하지만 상대 분야의 관행은 모르는 사람.
- 한쪽 분야의 상식을 다른 쪽 독자는 모른다고 가정한다. 분야 용어는 처음 나올 때 정의한다.
- **목소리:** 옆자리 선배가 아니라 **좋은 교과서**. 정확하고, 이유를 설명하고, 과장하지 않는다.
- 본문은 평서체(`-다`)로 쓴다. 독자에게 직접 지시하는 실습·체크리스트도 평서체(`~한다`)로 통일한다.
- "쉽게", "간단히", "당연히"를 쓰지 않는다. 독자에게 쉽지 않을 수 있다.

## 2. 설명의 순서

개념 절은 기본적으로 다음 순서를 따른다. 필요 없으면 생략하되 순서는 바꾸지 않는다.

1. **왜 필요한가** — 이 개념이 없으면 연구에서 무엇이 막히는가
2. **정의** — 정확한 정의와 가정
3. **직관** — 그림·예시·비유
4. **수식** — 유도 또는 핵심 식
5. **코드** — 수식과 1:1로 대응하는 최소 구현
6. **연구에서의 의미** — 실제 연구에서 어디에 쓰이고 어디서 틀리는가

## 3. 용어

- **한국어 우선, 첫 등장 시 영어 병기:** 조건부분포(conditional distribution).
- 연구 현장에서 영어를 그대로 쓰는 용어는 영어로 쓴다: batch, epoch, checkpoint, baseline, ablation, embedding, loss, metric.
  어색한 번역어를 새로 만들지 않는다.
- 용어 선택은 `data/glossary.toml`에 기록하고, 책 전체에서 같은 단어를 쓴다.
- 코드 식별자·명령·파일명은 항상 `코드 서식`으로 쓰고 번역하지 않는다.

## 4. 수식

- 인라인 `$...$`, 블록 `$$...$$` (KaTeX 호환 문법만 사용).
- 기호는 [부록 A. 표기법](../content/appendices/a-notation/index.md)을 따른다. 요약:
  - 스칼라 $x$, 벡터 $\mathbf{x}$, 행렬 $\mathbf{A}$, 집합 $\mathcal{D}$, 확률변수 $X$
  - 파라미터 $\theta$, 잠재변수 $z$, 손실 $L$, 데이터셋 $\mathcal{D}=\{(x_i,y_i)\}_{i=1}^N$
  - gradient는 열벡터, Jacobian은 (출력 차원 × 입력 차원)
- 수식 뒤에는 각 기호의 의미를 문장으로 설명한다.

## 5. 코드

- Python 3.11+, PyTorch 기준. 코드 블록에는 언어를 표시한다(` ```python `).
- 텐서에는 shape 주석을 단다: `x = encoder(x)  # (B, T, D)`
  - 축 이름 약어: `B` batch, `T` time, `C` channel, `D` feature, `H` head, `N` 샘플 수
- 물리량 변수에는 단위 접미사: `voltage_v`, `current_a`, `time_s`, `temp_c`
- 본문 코드는 **짧게**(대략 30줄 이하). 전체 코드는 `labs/`에 두고 링크한다.
- 실행 결과를 보여 줄 때는 실제로 실행한 결과만 쓴다.

## 6. 버전이 바뀌는 정보

- 도구 버전·설치 명령·제품 UI는 빠르게 낡는다. 본문에는 **확인 절차**를 쓰고, 구체적인 버전은 "집필 시점 예시"로 표시한다.
- 공식 문서 링크를 우선하고, 블로그 글은 보조 자료로만 쓴다.

## 7. 콜아웃(박스)

웹 프레임워크 확정 전까지는 아래 컨테이너 문법으로 쓴다(Starlight·Docusaurus·VitePress가 같은 문법을 지원한다).

```md
:::note[직관]
...
:::
```

| 종류 | 용도 |
|---|---|
| `note[직관]` | 그림·비유로 감 잡기 |
| `tip[연구 팁]` | 실제 연구에서의 요령 |
| `caution[함정]` | 본문 중간의 실패 사례 |
| `note[분야 예시]` | 과학 분야 사례 (물리·기후·화학·생명·배터리 등) |
| `note[심화]` | 건너뛰어도 되는 깊은 내용 |

## 8. 인용

- 외부 주장·수치·그림에는 출처를 단다. 원 논문을 우선 인용한다.
- AI 도구가 제시한 인용은 원문을 직접 확인한 뒤에만 쓴다.
