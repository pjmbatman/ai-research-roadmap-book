# 0001. 본문은 Git의 Markdown·TOML을 유일한 원천으로 한다
- 상태: 채택
- 날짜: 2026-11-03

## 맥락
웹 서비스로 공개할 책이지만, 웹 프레임워크와 화면 설계는 아직 정해지지 않았다. 본문이 특정 프레임워크나 DB에 묶이면 리뷰·버전 관리·자동 검증이 어려워진다.

## 결정
본문은 `content/`의 Markdown(+ frontmatter), 퀴즈는 TOML, 목록형 데이터는 `data/`의 TOML·BibTeX로 쓴다. 웹 사이트는 빌드 시 이 파일들을 읽는다. 콘텐츠를 DB에 넣지 않는다.

## 결과
- Pull request로 원고를 리뷰하고 `scripts/book.py check`로 구조를 검증할 수 있다.
- 사이트 프레임워크를 바꿔도 원고는 그대로다.
- 웹 전용 요소는 지시문(`::widget` 등)으로만 쓰며, GitHub에서도 읽힌다.
