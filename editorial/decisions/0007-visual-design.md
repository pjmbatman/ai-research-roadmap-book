# 0007. 하나의 테마와 적재적소의 효과로 시각 디자인을 정한다
- 상태: **대체됨** → [0010](0010-reference-based-design.md) (2026-11-06)
- 날짜: 2026-11-06

## 맥락
README 같은 정적 문서가 아니라, 시각화·모션·직접 조작으로 이해하는 서비스를 원한다. 시안 10개(오로라 도크, 성좌 지도, 청사진, 스크롤리텔링, 분할 실험대, 벤토 허브, 스위스 키네틱, 레이어 스택, 흐름장, 터미널 모노)를 비교했다.

## 결정
- 사이트 전체의 테마는 하나다: 메인 2색 Midnight `#0B1020` · Glacier `#DCE6F2`(90%) + 엣지 Coral `#FF6B5A`(10%). 다크·라이트 테마는 메인 두 색의 역할만 바꾼다.
- 시안들의 효과는 하나를 고르지 않고 **도구 상자**로 둔다. 기능에 맞는 효과를 적재적소에 쓰고, 한 페이지에서 여러 효과를 함께 써도 된다.
- 이론·실습·퀴즈 모두에서, 값을 바꿔 보면 이해가 빨라지는 곳에는 슬라이더와 직접 조작을 쓴다. 조작 규칙은 [design-system.md](../design-system.md) §6.
- 위젯은 인터랙션 틀(`kind`: manipulate · stepper · simulate · compare)로 분류해 공통 틀을 재사용한다.

## 결과
- 색·글꼴·모션 토큰과 효과 도구 상자, 인터랙션 원칙은 [design-system.md](../design-system.md)가 원천이다.
- `data/widgets.toml`에 `kind`가 필수가 되고, 수치 퀴즈에 슬라이더 응답(`slider`)이 추가된다. `check`가 둘 다 검증한다.
- 트랙은 색이 아니라 코드 배지와 아이콘으로 구분한다.
