# 0006. 사이트는 Astro와 React 아일랜드로 만든다
- 상태: 제안
- 날짜: 2026-11-06

## 맥락
본문은 정적으로 빠르게 읽혀야 하고, 위젯·편집기·Pyodide 같은 인터랙티브 요소는 필요한 곳에서만 활성화되어야 한다(0001, 0003, 0004).

## 결정 (제안)
Astro로 `content/`를 정적 페이지로 빌드하고, 위젯·편집기·퀴즈는 React 컴포넌트를 아일랜드로 붙인다. 수식은 KaTeX, 편집기는 CodeMirror 6.

## 결과
- 채택 여부는 M1 파일럿(장 2개)을 만들어 본 뒤 확정한다.
