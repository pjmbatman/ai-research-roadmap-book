# 0008. 공통 예제·분량 기준·장 명세 단계로 콘텐츠를 설계한다
- 상태: 채택(잠정) — 사용자 확인 대기
- 날짜: 2026-11-06

## 맥락
215개 장의 상세 목차는 있지만 본문 내용의 공통 기준이 없었다. 장마다 따로 쓰면 예제·깊이·표기가 들쭉날쭉해진다. v1 진행을 위해 사용자 부재 중 잠정 결정한다([plans/v1-prototype.md](../plans/v1-prototype.md)).

## 결정
- 공통 예제 세 개를 책 전체에서 반복해 쓴다: 감쇠 진동자, 열 방정식, 실제 배터리 사이클 데이터. 실 3의 데이터셋은 라이선스 확인 후 사용자와 정한다.
- 등급별 분량·깊이 기준, 두 독자를 위한 다리 상자, 표기법 기준, 참고 자료 정책은 [content-design.md](../content-design.md)를 따른다.
- 장 상태에 `spec`(명세)을 추가한다: `outline` → `spec` → `draft` → `review` → `done`.

## 결과
- 본문 집필 전에 장 명세를 검토할 수 있다.
- 사용자가 다른 공통 예제나 기준을 정하면 이 ADR을 대체하는 새 ADR을 쓴다.
