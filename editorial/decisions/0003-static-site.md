# 0003. 로그인 없는 정적 사이트로 공개한다
- 상태: 채택
- 날짜: 2026-11-04

## 맥락
오픈소스로 공개하며 로그인이 필요 없다. 예제는 CPU로 충분한 규모다.

## 결정
백엔드·DB·계산 서버를 두지 않는다. 사이트는 정적 파일로 빌드해 GitHub Pages로 배포한다. 진도는 브라우저 저장소에 두고 JSON으로 내보내기·가져오기를 제공한다. 퀴즈·테스트·해답은 공개된다.

## 결과
- 운영 비용과 보안 부담이 거의 없다.
- 기기 간 진도 동기화, 강사용 현황판, 정답 은닉은 제공하지 않는다.
