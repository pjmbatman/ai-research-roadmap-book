# 0004. 코드 실행은 런타임 어댑터로 학습자 자원에서 한다
- 상태: 채택
- 날짜: 2026-11-04

## 맥락
이론과 실습을 한 화면에서 해야 하지만 서버를 두지 않는다(0003).

## 결정
코드 블록은 필요한 환경(`exec="browser"|"python"|"gpu"`)만 선언한다. 프론트엔드의 런타임 어댑터가 브라우저 안 Pyodide(기본) 또는 학습자 컴퓨터의 `localhost` 커널(선택)을 고른다. 원격 어댑터는 확장 지점으로만 둔다.

## 결과
- 대부분의 예제는 설치 없이 실행된다.
- PyTorch 실습은 학습자가 로컬 런타임을 연결해야 한다. 브라우저의 로컬 네트워크 접근 허용이 필요하다.
- 연결하지 않은 독자를 위해 빌드 시 기록한 출력을 함께 보여 준다.
