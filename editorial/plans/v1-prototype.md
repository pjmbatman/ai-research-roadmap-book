# 계획: 프로토타입 v1 배포

> 이 파일은 v1까지의 **작업 계획 + 진행 기록**이다. 각 단계는 **게이트**(통과 조건)를 만족해야 다음 단계로 넘어간다.
> 사용자가 자리를 비운 동안 Claude가 이 계획을 따라 진행하고, 아래 진행 기록에 결과를 남긴다.

## 0. v1의 정의

**v1 = "로드맵 전체를 탐색할 수 있고, 두 개의 시범 장을 이론·위젯·코드·퀴즈로 끝까지 학습할 수 있는 공개 사이트."**

포함:
- 215개 장 전체가 사이트에 페이지로 존재(대부분 상세 목차 상태로 표시)
- 홈: 레이어·트랙 구조와 선수 지식 그래프 시각화
- 시범 장 2개(7.2 아핀 구조와 비선형성, 12.3 분포 기반 문제 정의): 본문 초고 + 위젯 + 브라우저 코드 실행 + 퀴즈 + 실습
- 부록 A 표기법
- 디자인 시스템(테마·floating dock·⌘K 검색), 브라우저 진도 저장·내보내기
- GitHub Pages 자동 배포 설정

제외(v2 이후): 로컬 런타임 어댑터, 터미널 실습, 나머지 장 본문, PDF, 영어판.
