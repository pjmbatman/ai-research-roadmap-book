# 디자인 시스템

> 상태: **채택** ([ADR 0012](decisions/0012-bento-quest-lab.md), 2026-11-07). 화면별 구조 레퍼런스는 [ADR 0010](decisions/0010-reference-based-design.md)과 [benchmarks.md](benchmarks.md)를 따른다.
> 이전 시스템은 대체했다: Liquid Glass(ADR 0011), shadcn 무채색 토큰(ADR 0010 §2), Midnight·Glacier·Coral 테마(ADR 0007).
> 원칙: 임의로 디자인하지 않는다. 화면 구조는 그 화면 유형의 레퍼런스를 따르고, 바꿀 때는 결정을 기록한다.

## 1. 원칙

1. **한 화면에 지금 할 것만.** 주석처럼 덧붙인 작은 글씨는 쓰지 않는다.
2. **스크롤 대신 넘기기.** 장은 노드로, 노드는 쪽으로, 퀴즈는 한 문항씩, 긴 목록은 탭으로 나눈다(ADR 0009).
3. **색은 의미가 있을 때만.** 바탕은 무채색이다. 파랑은 지금 할 것·진행, 초록은 완료·정답, 주황은 실습·학습 중, 빨강은 오답·오류에 쓴다.
4. **밀리거나 겹치지 않게.**
   - 격자·flex 자식에는 `min-width: 0`을 준다.
   - 높이는 고정하지 않고 `minmax(…, auto)`로 둔다.
   - 한 줄 라벨은 말줄임하고, 긴 본문은 그 칸 안에서만 스크롤한다.
   - 데스크톱(1440·1280), 태블릿(1180 이하), 휴대폰(390) 폭에서 가로 넘침이 없는지 e2e로 확인한다.

## 2. 토큰

**글꼴:** Pretendard(본문·제목), JetBrains Mono(코드·숫자 라벨, 합자 끔). 제목은 800–900 굵기에 자간 −0.02~−0.06em이다.

**색:** 면을 채우는 색과 글자로 쓰는 색(`*-ink`)을 나눈다. 글자 색은 배경 대비 4.5:1 이상이다.

| 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| `--bg` | `#f5f5f7` | `#0b0b0d` | 페이지 바탕 |
| `--surface` / `--surface-2` | `#ffffff` / `#f2f2f6` | `#1c1c1e` / `#232326` | 타일·시트 / 그 안의 면 |
| `--ink` / `--ink-2` / `--mute` | `#1d1d1f` / `#48484d` / `#6e6e73` | `#f5f5f7` / `#d1d1d6` / `#a1a1a6` | 글자(본문 / 보조 / 라벨) |
| `--line` · `--soft` | `#e3e3e8` · `#ececf1` | `#38383a` · `#2c2c2e` | 테두리 · 빈 막대 |
| `--blue` · `--blue-ink` · `--blue-edge` | `#0071e3` · `#0062c4` · `#0057b3` | `#0a84ff` · `#64a8ff` · `#0060c0` | 주 버튼·지금 할 노드·링크 |
| `--green` · `--green-ink` · `--green-edge` | `#34c759` · `#1c7c35` · `#23963f` | `#30d158` · `#4ade80` · `#1f9a40` | 완료·정답(초록 위 글자는 진한 녹색 `#0b2e15`) |
| `--orange` · `--orange-ink` · `--orange-edge` | `#ff9f0a` · `#a65a00` · `#c97a00` | `#ff9f0a` · `#ffb340` · `#c47800` | 실습실·학습 중(주황 위 글자는 `#2a1a00`) |
| `--red` · `--red-ink` | `#ff3b30` · `#c8102e` | `#ff453a` · `#ff6961` | 오답·오류 |
| `*-soft` | 각 색의 옅은 바탕 | 각 색의 어두운 바탕 | 피드백 띠·상태 칩 |

**트랙 색:** 트랙마다 두 색 그라데이션(`lib/cover.ts`)이다. 커버, 메인 히어로, 퀘스트 단원 카드, 로드맵 주제 노드에 쓴다.

**모서리:** 타일·시트 28px, 카드 20px, 컨트롤 14px, 알약 999px.

**그림자:**
- 타일: `0 1px 2px` + `0 10px 30px -18px`.
- Clay: 아래 판 `0 7px 0 var(--clay)` + 퍼지는 그림자. 누르면 판이 줄어든다.

**움직임:**
- 등장은 rise 600ms이고, 타일마다 60ms씩 늦춘다.
- 시트는 스프링으로 떠오르고, 쪽은 좌우로 미끄러진다.
- 지금 할 노드는 1.8s마다 들썩인다.
- `prefers-reduced-motion`이면 모두 끈다.

## 4. 위젯

- 틀은 카드다. 머리에는 제목과 초기화 버튼, 본문에는 그림, 바닥에는 조작을 둔다.
- 그림 바탕은 `--card`다. 격자와 축은 `--border`·`--muted-foreground`, 주된 데이터는 `--chart-3`, 보조 데이터는 `--chart-1`로 그린다.
- 조작은 프리셋 묶음, 슬라이더, 스위치만 쓴다.
- 수업 시트 안에서는 캔버스가 시트 높이에 들어가도록 폭을 줄인다.
