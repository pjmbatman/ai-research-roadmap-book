# 디자인 시스템

> 상태: **채택** ([ADR 0010](decisions/0010-reference-based-design.md) 구조 + [ADR 0011](decisions/0011-liquid-glass-dashboard.md) 시각 언어, 2026-11-06). §2의 shadcn 토큰은 크기·간격 기준으로 남고, 색·재질은 §5(Liquid Glass)가 우선한다. 이전 시스템(ADR 0007: Midnight·Glacier·Coral 테마, floating dock, 효과 도구 상자, 위젯 종류)은 **폐기**했다.
> 원칙: 임의로 디자인하지 않는다. 시각 언어는 검증된 오픈소스 디자인 시스템을 그대로 쓰고, 화면 구조는 그 화면 유형에서 가장 인기 있는 레퍼런스를 따른다. 근거는 [benchmarks.md](benchmarks.md).

## 1. 원칙

1. **레퍼런스 우선.** 새 컴포넌트나 화면을 만들 때는 먼저 §3의 레퍼런스에서 같은 기능을 찾고 그 구조를 따른다. 레퍼런스가 없으면 만들기 전에 결정을 기록한다.
2. **심플하고 간결하게.** 화면에는 지금 필요한 것만 둔다. 주석처럼 덧붙인 작은 글씨는 쓰지 않는다 (사용자 원칙, ADR 0009).
3. **스크롤 대신 넘기기.** 장은 단계로, 퀴즈는 한 문항씩, 긴 목록은 탭으로 나눈다 (ADR 0009).
4. **색은 의미가 있을 때만.** 바탕은 무채색이고, 색은 상태(완료·학습 중·오답)와 데이터에만 쓴다.

## 2. 시각 기반: shadcn/ui (neutral)

토큰은 shadcn/ui v4 사이트의 `globals.css`(github.com/shadcn-ui/ui, `apps/v4/app/globals.css`, 2026-11-06 확인) 값을 그대로 쓴다. 색 공간은 OKLCH다.

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--background` | `oklch(1 0 0)` | `oklch(0.145 0 0)` | 페이지 바탕 |
| `--foreground` | `oklch(0% 0 0)` | `oklch(0.985 0 0)` | 본문 글자 |
| `--card` | `oklch(1 0 0)` | `oklch(0.205 0 0)` | 카드·위젯 바탕 |
| `--primary` / `--primary-foreground` | `oklch(0% 0 0)` / `oklch(0.985 0 0)` | `oklch(0.922 0 0)` / `oklch(0.205 0 0)` | 주 버튼 |
| `--secondary`, `--muted`, `--accent` | `oklch(0.97 0 0)` | `oklch(0.269 0 0)` (`accent` 0.371) | 보조 버튼·탭 목록·호버 |
| `--muted-foreground` | `oklch(0.556 0 0)` | `oklch(0.708 0 0)` | 보조 글자 |
| `--border`, `--input` | `oklch(0.922 0 0)` | `oklch(1 0 0 / 10%)`, `/ 15%` | 테두리 |
| `--ring` | `oklch(0.708 0 0)` | `oklch(0.556 0 0)` | 포커스 |
| `--destructive` | `oklch(0.577 0.245 27.325)` | `oklch(0.704 0.191 22.216)` | 오답·오류 |
| `--chart-1…5` | Tailwind blue 300·500·600·700·800 | 같음 | 데이터·위젯 |
| `--radius` | `0.625rem` | | `sm` 0.6×, `md` 0.8×, `lg` 1×, `xl` 1.4× |

상태 색은 Tailwind v4 팔레트(`theme.css`)에서 가져온다.

| 상태 | 색 |
|---|---|
| 완료·정답 | green-600 `oklch(62.7% 0.194 149.214)` |
| 학습 중 | amber-500 `oklch(76.9% 0.188 70.08)` |
| 오답·오류 | `--destructive` |

글꼴은 한국어를 지원하는 Pretendard(본문)와 JetBrains Mono(코드)다. 글자 크기는 13·14·16·18·20·24·30·36px만 쓴다.

**컴포넌트**는 shadcn/ui의 이름과 모양을 따른다.
- **Button**: default · secondary · outline · ghost, 높이 36px, `radius-md`
- **Card**: 테두리 + `radius-xl` + 그림자 xs
- **Badge**
- **Tabs**: muted 바탕 목록 안에서 선택된 탭만 바탕색
- **Progress**: 높이 8px, primary/20 바탕
- **Dialog**와 **Sheet**: 옆에서 나오는 서랍
- **Command**: ⌘K 검색
- **Slider**, **Switch**, **ToggleGroup**

움직임은 shadcn/ui의 등장·퇴장만 쓴다. 투명도와 확대·이동을 150–200ms로 바꾼다.

| 목차만 있는 장 | — | 학습 목표 카드 + 절별 카드(본문이 생기면 레슨으로 바뀐다) |

## 4. 위젯

- 틀은 Card다. 머리에는 제목과 초기화 버튼만, 본문에는 그림, 바닥에는 조작을 둔다.
- 그림 바탕은 `--card`(테마를 따른다)다. 격자와 축은 `--border`·`--muted-foreground`로 그린다. 주된 데이터는 `--chart-3`(blue-600), 보조 데이터는 `--chart-1`(blue-300), 사용자가 지금 바꾸는 대상은 `--foreground`로 그린다.
- 조작은 ToggleGroup(프리셋·단계), Slider(연속값), Switch(켜고 끄기)만 쓴다.
- 위젯마다의 조작 명세는 그 위젯을 쓰는 장의 명세에 쓴다.

## 5. 시각 언어: Liquid Glass + 대시보드 (ADR 0011)

**재질**
| 이름 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| 창 유리 `--glass` | `rgb(255 255 255 / 0.58)` + blur 40px · saturate 180% | `rgb(40 40 46 / 0.58)` | 큰 창, 탭 막대, 알약, 서랍 |
| 안쪽 면 `--fill` | `rgb(255 255 255 / 0.55)` (블러 없음) | `rgb(255 255 255 / 0.06)` | 창 안의 카드 |
| 테두리 | `rgb(255 255 255 / 0.7)` + 위쪽 안쪽 하이라이트 | `rgb(255 255 255 / 0.12)` | 유리 가장자리 |
| 어두운 패널 | `rgb(22 22 26 / 0.86)` | 같음 | 대시보드 오른쪽 패널 |

**글자 색** (Apple HIG): label `#1d1d1f` / `#f5f5f7`, secondaryLabel `rgb(60 60 67 / 0.6)` / `rgb(235 235 245 / 0.6)`.
**시스템 색** (Apple HIG, 라이트/다크): blue `#007AFF`/`#0A84FF` (강조·진행), green `#34C759`/`#30D158` (완료·정답), orange `#FF9500`/`#FF9F0A` (학습 중), red `#FF3B30`/`#FF453A` (오답·오류).
**모서리**: 창 32px, 카드 20px, 알약 999px. **그림자**: 창 `0 30px 80px -20px rgb(0 0 0 / 0.35)`.
**배경 환경**: 화면 전체에 고정된 흐린 그라데이션 메시(따뜻한 실내 톤, 다크는 저녁 톤).
**커버**: 트랙마다 두 색 그라데이션, 장 id로 정해지는 추상 구도(동심원·점 격자·띠·궤도), 왼쪽 위 트랙 코드, 아래 장 번호.

**셸**: 왼쪽 세로 알약 탭 막대(아이콘 + 가리키면 이름) → 큰 유리 창. 모바일은 아래 가로 알약.
**대시보드(홈)**: 위 인사·검색 → 이어서 학습(커버 카드) → 이번 주 목표 게이지 + 숫자 카드 → 트랙 커버 격자 / 오른쪽 어두운 패널(로드맵 요약·시작 버튼).
**장 읽기**: 위 주소창 알약(닫기·제목·단계 목록) + 창 + 아래 재생 막대 알약(이전·진행·k/N·다음).
