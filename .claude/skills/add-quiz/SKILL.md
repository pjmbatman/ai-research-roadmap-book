# 퀴즈 문항 추가

## 준비

1. 장 파일의 `## 학습 목표`를 읽고 번호를 매긴다(1부터).
2. 기존 `quiz.toml`이 있으면 읽고, 목표별 문항 수를 센다. 문항이 적은 목표부터 채운다.
3. 형식은 `editorial/conventions.md` §9, 원칙은 `editorial/roadmap-design.md` §4.1.

## 문항 쓰기

- 한 문항 = 한 학습 목표(`objective`).
- 암기 대신 **오개념을 드러내는** 문항. 오답 선택지는 실제로 흔한 착각이어야 하고, 각각 `feedback`을 단다.
- 모든 문항에 `explanation`. 왜 정답인지와, 대표 오답이 왜 틀렸는지.
- 수식이 들어간 문자열은 리터럴 문자열(`'''...'''`).
- `numeric` 문항은 손으로 계산 가능한 크기, `tolerance` 명시.
- 문항 `id`는 kebab-case, 장 안에서 고유. 이미 있는 `id`는 바꾸지 않는다(학습자 기록의 키).

## 검증

- **모든 정답을 직접 풀어서 확인한다.** 계산 문항은 코드로 확인한다.
- 실행한다.

  ```bash
  python3 scripts/book.py check
  ```

- 커밋 메시지: `quiz(<부>.<장>): <요약>`
