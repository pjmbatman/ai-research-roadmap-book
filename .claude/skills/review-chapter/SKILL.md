# 장 리뷰

장을 고치지 않고 **보고서만** 쓴다. 고치는 일은 리뷰 결과를 본 사람이 결정한다.

## 점검 항목 (심각한 것부터)

1. **사실·인용:** 확인할 수 없는 주장, 출처 없는 수치, 존재가 의심되는 논문·API. 원문을 확인할 수 있으면 확인한다.
2. **수식:** 유도의 각 단계, 기호가 부록 A 표기법과 일치하는지, 차원·shape·단위.
3. **코드:** `labs/`의 실습과 본문 코드 블록을 실제로 실행해 본문의 출력과 일치하는지. `exec` 값이 맞는지(browser 블록에 PyTorch 금지).
4. **퀴즈:** 정답이 맞는지 직접 풀어 확인. 오답 선택지가 실제 오개념인지, feedback·explanation이 있는지, objective가 학습 목표와 맞는지.
5. **교육적 구성:** 학습 목표를 본문이 실제로 다루는지, 통과 기준이 산출물로 확인 가능한지, 선수 지식(`prerequisites`)이 빠지거나 과한지.
6. **문체:** style-guide 위반(평서체, 용어 병기, "쉽게" 등 금지어).
7. **구조:** `python3 scripts/book.py check` 결과.

## 보고서 형식

| 심각도 | 위치 | 문제 | 근거 | 제안 |
|---|---|---|---|---|
| 높음 / 중간 / 낮음 | 절 제목 또는 파일:줄 | 무엇이 틀렸나 | 확인한 방법 | 고치는 방법 |

마지막에 "확인하지 못한 항목"을 따로 적는다. `status`는 바꾸지 않는다.
