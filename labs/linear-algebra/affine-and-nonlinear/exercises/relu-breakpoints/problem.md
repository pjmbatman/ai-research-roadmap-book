# ReLU 합의 꺾이는 점 찾기

1차원 함수

$$
f(x) = \sum_{j=1}^{n} c_j \,\mathrm{ReLU}(w_j x + b_j)
$$

는 조각별 아핀 함수다. 함수 `breakpoints(c, w, b)`를 완성해 **기울기가 실제로 바뀌는 점**들을 오름차순 NumPy 배열로 반환한다.

- 뉴런 $j$는 $w_j x + b_j = 0$인 점, 즉 $x = -b_j / w_j$에서 꺾일 수 있다.
- 그 점에서 기울기는 $c_j \lvert w_j \rvert$만큼 바뀐다. $w_j > 0$이면 왼쪽 기울기 0이 오른쪽에서 $c_j w_j$가 되고, $w_j < 0$이면 왼쪽 기울기 $c_j w_j$가 오른쪽에서 0이 된다.
- 여러 뉴런이 **같은 점**에서 꺾이면 기울기 변화가 더해진다. 합이 0이면 그 점은 꺾이는 점이 아니다.
- $w_j = 0$이거나 $c_j = 0$인 뉴런은 꺾이는 점을 만들지 않는다.

같은 점인지 판정할 때와 기울기 변화가 0인지 판정할 때는 허용 오차 `tol`을 쓴다. 아핀 조각의 수는 `len(breakpoints(...)) + 1`이다.
