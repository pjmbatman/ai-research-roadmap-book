# 스칼라 자동미분 엔진 만들기

본문의 엔진을 직접 다시 만든다. `Value`는 스칼라 값 `data`, 그 값에 대한 출력의 gradient `grad`, 이 노드를 만든 입력 노드 `parents`, 각 입력에 대한 국소 미분 `local_grads`를 가진다. 생성자는 주어져 있다.

다음 네 메서드를 완성한다.

| 메서드 | 순전파 값 | 기록할 국소 미분 |
|---|---|---|
| `a + b` (`__add__`) | $a + b$ | $(1, 1)$ |
| `a * b` (`__mul__`) | $ab$ | $(b, a)$ |
| `a.tanh()` | $t = \tanh a$ | $(1 - t^2,)$ |
| `out.backward()` | — | 아래 설명 |

`backward()`는 `out.grad = 1`로 두고, 그래프의 노드를 **위상 순서의 역순**(출력에서 입력 쪽)으로 방문하며 각 노드 `v`의 입력 `p`에 `p.grad += local * v.grad`를 더한다.

`b`가 `Value`가 아닌 숫자(`float`, `int`)여도 `a + 2.0`, `a * 3`이 동작해야 한다. 숫자는 `Value`로 감싼다.

테스트가 확인하는 것:

- 뉴런 하나 $\tanh(w_1x_1 + w_2x_2 + b)$의 gradient가 손 유도와 같은가.
- 같은 노드를 여러 번 쓰는 식 $z = u \cdot u + u$에서 $dz/du = 2u + 1$인가. gradient를 **덮어쓰지 말고 더해야** 한다.
- 마름모 모양 그래프 $a = xy,\ c = a \cdot (a + x)$에서 위상 순서가 맞는가. 어떤 노드의 gradient를 그 노드를 쓰는 모든 노드가 처리되기 전에 전달하면 틀린다.

힌트: 위상 정렬은 깊이 우선 탐색으로 만든다. 노드의 모든 입력을 먼저 방문한 뒤 자신을 리스트에 넣으면, 리스트의 역순이 출력에서 입력으로 가는 순서다.
