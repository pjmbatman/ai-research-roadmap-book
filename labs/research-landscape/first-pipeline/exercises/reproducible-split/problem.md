# 다시 실행해도 같은 분할

"다른 사람이 같은 명령으로 같은 숫자를 다시 얻는다"의 첫 조건은 **같은 분할**이다. 함수 `split_indices(n, fractions, seed)`를 완성해 학습·검증·테스트 인덱스 배열 세 개를 반환한다.

- `fractions = (f_train, f_val, f_test)`이고 합은 1이다.
- 크기는 `n_train = int(f_train * n)`, `n_val = int(f_val * n)`, 나머지는 모두 테스트다. 따라서 세 배열을 합치면 `0, 1, …, n-1`이 **빠짐없이, 겹치지 않게** 들어 있다.
- `0, …, n-1`을 무작위로 섞은 뒤 앞에서부터 잘라 나눈다.
- 무작위성은 `np.random.default_rng(seed)`로 만든 **자기만의 난수 생성기**에서만 얻는다. 전역 난수 상태(`np.random.seed`, `np.random.permutation`)를 쓰지도, 바꾸지도 않는다.

테스트는 다음을 확인한다.

1. 크기, 겹침 없음, 빠짐없음
2. 같은 `seed`이면 같은 분할, 다른 `seed`이면 다른 분할
3. 함수 밖에서 `np.random.seed(...)`를 바꾸거나 다른 난수를 먼저 뽑아도 결과가 같은지
4. 함수를 불러도 전역 난수 상태가 바뀌지 않는지

3–4번이 중요한 이유: 전역 난수 상태에 기대는 코드는 앞에서 어떤 코드가 몇 번 난수를 뽑았는지에 따라 분할이 달라진다. 셀 실행 순서나 import 순서만 바뀌어도 숫자가 바뀐다.
