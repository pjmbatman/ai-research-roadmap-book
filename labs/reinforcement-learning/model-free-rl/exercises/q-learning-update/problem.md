# Q-learning 갱신

경험 $(s, a, r, s')$ 하나로 행동 가치 표를 갱신한다.

$$
Q(s, a) \leftarrow Q(s, a) + \alpha\Big[r + \gamma \max_{a'} Q(s', a') - Q(s, a)\Big].
$$

$s'$가 종료 상태이면 그 뒤의 가치는 0이므로 목표는 $r$뿐이다. 함수 `q_learning_update(Q, s, a, r, s_next, done, alpha, gamma)`를 완성해 갱신된 표를 반환한다.

| 인자 | 뜻 |
|---|---|
| `Q` | shape `(S, A)`의 행동 가치 표. **바꾸지 않고** 복사본을 갱신해 반환한다 |
| `s`, `a`, `s_next` | 정수 상태·행동 번호 |
| `r` | 받은 보상 |
| `done` | `s_next`가 종료 상태이면 `True` |
| `alpha`, `gamma` | 학습률, 할인율 |

테스트는 손으로 계산한 갱신(퀴즈와 같은 값 2.85), `Q[s, a]` 말고는 바뀌지 않는지, 종료 처리, 목표에 평균이 아니라 $\max$를 쓰는지, 작은 사슬에서 무작위 경험으로 반복하면 $Q^*$로 수렴하는지 확인한다.

생각해 볼 것: 목표의 $\max_{a'} Q(s', a')$를 실제로 다음에 고른 행동의 $Q(s', a')$로 바꾸면 SARSA가 된다. 두 갱신이 같은 경험에서 다른 값을 내는 예를 하나 만들어 본다.
