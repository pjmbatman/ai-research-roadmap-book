# UCB로 팔 고르기

UCB 규칙은 팔마다 평균 보상에 불확실성 보너스를 더한 지표

$$
\mathrm{UCB}_a(t) = \frac{S_a}{n_a} + c\sqrt{\frac{\ln t}{n_a}}
$$

가 가장 큰 팔을 고른다. $n_a$는 팔 $a$의 시행 수, $S_a$는 보상 합, $t$는 지금까지의 총 시행 수다. $c = \sqrt{2}$이면 본문의 UCB1이다.

함수 `ucb_select(counts, sums, t, c=np.sqrt(2))`를 완성해 팔 번호(정수)를 반환한다.

- 한 번도 당기지 않은 팔($n_a = 0$)이 있으면 지표를 계산하지 말고 그중 번호가 가장 작은 팔을 반환한다.
- 그 밖에는 지표가 가장 큰 팔을 반환한다.

테스트는 시도하지 않은 팔 처리, 퀴즈의 예($t = 55$에서 시행 5번인 팔 선택), 시행이 충분할 때의 활용, $c$에 따른 변화, 그리고 실제 Bernoulli 밴딧 1500번에서 대부분 최선 팔을 고르면서도 나쁜 팔을 가끔 다시 시도하는지 확인한다.

생각해 볼 것: $c$를 0으로 두면 어떤 알고리즘이 되고, 왜 최선 팔을 영영 놓칠 수 있는가?
