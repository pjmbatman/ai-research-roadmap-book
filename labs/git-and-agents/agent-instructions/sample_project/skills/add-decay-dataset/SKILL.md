# 합성 자료 조건 추가

## 절차

1. 사용자에게서 반감기(초), 초기 계수, 측정 시간(초)을 받는다. 단위가 없으면 묻는다.
2. `tests/test_halflife.py`에 새 조건을 **추가**한다. 기존 조건과 기대값은 바꾸지 않는다.
3. 기대 오차는 근거와 함께 정한다. 기본은 상대 오차 5%이고, 측정 시간이 반감기의 2배보다 짧으면 사용자에게 허용 오차를 확인받는다.
4. 다음을 실행하고 둘 다 통과해야 끝난다.

   ```bash
   python -m pytest -q tests
   python src/halflife.py --smoke
   ```

5. 추가한 조건, 실행한 명령, 결과를 보고한다. 실패하면 테스트를 고치지 말고 실패 내용을 보고한다.
