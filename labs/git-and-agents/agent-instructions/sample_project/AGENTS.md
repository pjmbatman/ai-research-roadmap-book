# 에이전트 지침 — 반감기 추정 프로젝트

방사성 붕괴 계수 자료에서 반감기를 추정하는 최소 연구 프로젝트다. 코드는 `src/`, 테스트는 `tests/`에 있다.

## 명령

모든 명령은 이 디렉터리에서 실행한다. 필요한 패키지: numpy, pytest.

```bash
python -m pytest -q tests
python src/halflife.py --smoke
```

- 코드를 고친 뒤에는 위 두 명령이 모두 통과해야 작업이 끝난 것이다.
- `--smoke`는 1초 안에 끝나는 합성 자료 점검이다. 실제 자료 분석은 사람이 실행한다.

## 규칙

- 물리량 변수에는 단위 접미사를 붙인다(`t_s`, `half_life_s`).
- `tests/`의 기대값을 바꾸지 않는다. 바꿔야 한다고 판단하면 이유를 보고하고 멈춘다.
- `data/`(실측 자료)는 읽기만 한다. 수정·삭제·외부 전송을 하지 않는다.
- 새 의존성을 추가하지 않는다.
