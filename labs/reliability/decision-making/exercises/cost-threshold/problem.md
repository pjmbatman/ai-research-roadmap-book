# 비용으로 정하는 경보 threshold

고장 확률 $p$를 내는 모델로 점검 경보를 낸다. 경보를 냈는데 정상이면 비용 $c_{FP}$(불필요한 점검), 경보를 내지 않았는데 고장이면 비용 $c_{FN}$(놓친 고장)이 든다. $p$가 보정되어 있으면, 경보를 낼 때의 기대 비용 $(1-p)\,c_{FP}$가 내지 않을 때의 기대 비용 $p\,c_{FN}$보다 작을 때 경보를 내는 것이 최적이므로

$$
p > \frac{c_{FP}}{c_{FP} + c_{FN}}
$$

이 결정 규칙이다. 모델의 보정이 의심스러우면 검증 데이터에서 비용을 직접 최소화하는 threshold를 고른다.

세 함수를 완성한다.

1. `bayes_threshold(c_fp, c_fn)`: 위 식의 threshold
2. `mean_cost(p, y, thr, c_fp, c_fn)`: `p > thr`이면 경보로 보고, 관측 `y`(1 = 고장, 0 = 정상)에 대한 사례당 평균 비용
3. `best_threshold(p, y, c_fp, c_fn, grid)`: 후보 배열 `grid` 중 `mean_cost`가 가장 작은 threshold (동률이면 앞의 것)

테스트는 손으로 계산한 예, 보정된 확률에서 2번·3번의 답이 1번 근처인지, 그리고 보정이 틀린 확률에서는 3번이 1번보다 비용이 작은지 확인한다.
