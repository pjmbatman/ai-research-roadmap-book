# Benjamini–Hochberg 절차 구현하기

검정 $m$개의 p-value가 있을 때, Benjamini–Hochberg(BH) 절차는 거짓 발견 비율의 기댓값(FDR)을 $q$ 이하로 유지하면서 기각할 가설을 고른다.

1. p-value를 작은 순서로 정렬한다: $p_{(1)} \le p_{(2)} \le \dots \le p_{(m)}$
2. $p_{(k)} \le \dfrac{k}{m}\,q$를 만족하는 **가장 큰** 순위 $k$를 찾는다.
3. 순위 $1, \dots, k$의 가설을 모두 기각한다. 그런 $k$가 없으면 아무것도 기각하지 않는다.

`bh_reject(pvals, q=0.05)`를 완성한다. 입력과 **같은 순서**의 boolean 배열(기각하면 `True`)을 반환한다.

주의: 2단계는 "작은 쪽부터 조건을 확인하다 처음 실패하면 멈춘다"가 아니다. 조건을 만족하는 가장 큰 순위를 찾고, 그보다 작은 순위는 조건을 만족하지 않아도 모두 기각한다(step-up 절차). 테스트에 이 차이를 드러내는 예가 있다.
