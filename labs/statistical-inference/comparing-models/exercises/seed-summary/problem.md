# seed 결과 요약: 표준편차, 표준오차, 짝지은 차이

같은 실험을 seed만 바꿔 여러 번 실행한 점수를 보고용 숫자로 요약하는 두 함수를 완성한다.

1. `summarize(scores)`: 점수 배열 하나를 받아 사전 `{"n", "mean", "sd", "se"}`를 반환한다.
   - `sd`는 실행 사이의 퍼짐을 나타내는 표본 표준편차($n-1$로 나눈다).
   - `se`는 평균의 표준오차 $\mathrm{sd}/\sqrt{n}$이다.
2. `paired_summary(a, b, t_crit)`: 같은 seed(같은 분할)에서 얻은 두 방법의 점수 `a[i]`, `b[i]`를 받아 차이 $d_i = b_i - a_i$를 요약한다. 사전 `{"mean_diff", "se", "lo", "hi", "wins_b"}`를 반환한다.
   - `se`는 차이 $d_i$의 표준오차.
   - `lo`, `hi`는 `mean_diff ∓ t_crit * se`. `t_crit`은 호출하는 쪽이 자유도 $n-1$에 맞춰 넘긴다(예: $n = 5$이면 2.776).
   - `wins_b`는 $b_i < a_i$인 seed의 수(점수가 오차라서 작을수록 좋다고 가정한다).

테스트는 표준편차와 표준오차를 구분하는지, 짝지은 차이가 seed마다 공통인 변동을 상쇄하는지 확인한다.
