# Kahan 보정 합

float32 배열의 원소를 앞에서부터 하나씩 더하면, 합이 커질수록 작은 원소의 아래쪽 자릿수가 반올림으로 사라진다. **Kahan 보정 합**(compensated summation)은 덧셈마다 잃은 부분을 보정 변수 $c$에 모아 다음 덧셈에서 되돌려 준다.

$$
y = x_i - c, \qquad t = s + y, \qquad c = (t - s) - y, \qquad s = t.
$$

$t - s$는 이번 덧셈에서 실제로 더해진 양이고, 여기서 $y$를 빼면 반올림으로 잃은 부분(의 음수)이 남는다.

함수 `kahan_sum(a)`를 완성한다.

- `a`는 1차원 float32 배열이다. **모든 중간 계산을 float32로** 한다(`np.float32(0)`에서 시작하고 원소를 float64로 바꾸지 않는다).
- 반환값은 float32 스칼라다.
- `np.sum`, `math.fsum`을 쓰지 않는다.

테스트는 float64로 계산한 합과 비교해, 순서대로 더한 합보다 오차가 크게 작은지 확인한다.

주의: 보정 식 `c = (t - s) - y`를 대수적으로 정리하면 0이 된다. 수학적으로 같은 식이 부동소수점에서는 다르다는 것이 이 알고리즘의 핵심이다.
