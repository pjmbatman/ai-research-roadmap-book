# ABC rejection의 수용 단계

참조 테이블에 시뮬레이션 $N$개의 파라미터 `theta_sim` (shape `(N,)`)와 요약 통계 `S_sim` (shape `(N, k)`)이 있다. 관측 데이터의 요약 통계는 `s_obs` (shape `(k,)`)다. 함수 `abc_accept(theta_sim, S_sim, s_obs, q)`를 완성해 **받아들인 파라미터** 배열을 반환한다.

1. 통계마다 척도가 다르므로, 각 열을 참조 테이블에서 잰 표준편차로 나눈다. `s_obs`도 같은 값으로 나눈다.
2. 표준화한 공간에서 각 시뮬레이션과 관측값 사이의 유클리드 거리 $d_i$를 계산한다.
3. 거리의 $q$ 분위수 이하인 시뮬레이션을 받아들이고, 그 `theta_sim` 값을 반환한다.

테스트는 다음을 확인한다.

- 받아들인 개수가 약 $qN$개인지
- 받아들인 표본의 거리가 거부한 표본의 거리보다 모두 작거나 같은지
- 척도가 1000배 큰 통계가 있어도 표준화 덕분에 결과가 바뀌지 않는지
- 정보가 있는 통계를 쓰면 받아들인 θ가 참값 근처에 모이는지

힌트: 본문 셀 2의 `abc` 함수가 같은 일을 한다. 여기서는 열 선택 없이 `S_sim`의 모든 열을 쓴다.
