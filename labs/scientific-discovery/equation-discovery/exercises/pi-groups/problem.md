# Buckingham π 그룹의 지수 구하기

물리량 $n$개의 차원을 기본 차원 $k$개(예: 질량, 길이, 시간)의 지수로 쓴 차원 행렬 `D` (shape `(k, n)`)가 있다. 열 $i$는 물리량 $q_i$의 차원이다. 무차원 조합 $\Pi = \prod_i q_i^{e_i}$의 지수 벡터 $\mathbf{e}$는 $\mathbf{D}\mathbf{e} = \mathbf{0}$을 만족한다.

함수 `pi_exponents(D, rep, target)`을 완성한다.

- `rep`: 반복 변수의 열 번호 목록. 반복 변수들의 차원 행렬 `D[:, rep]`은 가역이라고 가정한다(정사각, rank가 $k$).
- `target`: π 그룹에 지수 1로 들어갈 변수의 열 번호.
- 반환: 길이 $n$의 지수 벡터 `e`. `e[target] = 1`, 반복 변수 자리에는 무차원이 되도록 푼 지수, 나머지는 0.

예: 진자의 $(T, L, g, m, \theta_0)$에서 `rep = [1, 2, 3]`, `target = 0`이면 $\Pi = T L^{-1/2} g^{1/2}$이므로 `[1, -0.5, 0.5, 0, 0]`이다.

테스트는 다음을 확인한다.

- 반환한 `e`가 $\mathbf{D}\mathbf{e} = \mathbf{0}$을 만족하는지
- 진자 예와 유체 항력 예(항력 계수, Reynolds 수)에서 알려진 지수가 나오는지
- 반복 변수도 목표 변수도 아닌 변수의 지수는 0인지

힌트: 반복 변수의 지수 $\mathbf{x}$는 `D[:, rep] @ x = -D[:, target]`의 해다. 본문 셀 3과 같다.
