# 측정된 점들의 Pareto front

자율 실험이 수율과 순도처럼 여러 목적을 함께 측정했다. 측정값 `F` (shape `(N, k)`)의 각 행은 실험 하나, 각 열은 목적 하나이고, **모든 목적은 클수록 좋다**.

실험 $a$가 실험 $b$를 **지배**(dominate)한다는 것은 $a$가 모든 목적에서 $b$보다 같거나 크고, 적어도 하나의 목적에서 엄격하게 크다는 뜻이다. 어떤 실험에도 지배되지 않는 실험들이 Pareto front다.

함수 `pareto_mask(F)`를 완성해 길이 $N$의 불리언 배열을 반환한다. `True`는 그 실험이 Pareto front에 있다는 뜻이다.

테스트는 다음을 확인한다.

- 손으로 정답을 알 수 있는 작은 예
- 완전히 같은 측정값이 두 개 있으면 둘 다 front에 남는지(서로를 지배하지 않는다)
- 목적이 하나뿐이면 최댓값만 남는지
- front의 어떤 점도 다른 점에 지배되지 않고, front 밖의 모든 점은 front의 어떤 점에 지배되는지

힌트: $N$이 수백 이하이면 모든 쌍을 비교하는 $O(N^2 k)$ 방법으로 충분하다. 브로드캐스팅으로 `(N, N, k)` 비교 배열을 만들 수 있다.
