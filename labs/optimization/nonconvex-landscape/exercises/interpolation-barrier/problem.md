# 선형 보간 경로의 손실 장벽

학습된 두 해 $\theta_a$, $\theta_b$를 잇는 선분 $\theta(t) = (1 - t)\,\theta_a + t\,\theta_b$ 위에서 손실을 재면, 두 해 사이를 손실이 높아지지 않고 곧장 갈 수 있는지 알 수 있다. 경로 위 최대 손실이 양 끝보다 얼마나 높은지를 **장벽**(barrier)이라 한다.

$$
\text{barrier} = \max_{t \in [0, 1]} L(\theta(t)) - \max\big(L(\theta_a),\ L(\theta_b)\big).
$$

함수 `interpolation_barrier(loss, a, b, num=21)`를 완성한다. 0부터 1까지 균등 간격 `num`개의 $t$에서 손실을 계산해 `(ts, losses, barrier)`를 반환한다. 장벽은 격자 위의 최댓값으로 근사한다.

테스트는 다음을 확인한다.

- 반환값의 shape과 양 끝의 손실
- 볼록 함수에서는 장벽이 0이다(현이 그래프 위에 있다는 10.1장의 정의)
- 이중 우물 $(x^2 - 1)^2$의 두 최솟점 사이 장벽은 1이다
- 장벽은 경로 최대에서 **양 끝 중 큰 값**을 뺀 것이다
