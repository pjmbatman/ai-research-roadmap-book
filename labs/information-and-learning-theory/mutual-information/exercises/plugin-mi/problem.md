# 도수표에서 plug-in 상호정보량 계산하기

두 이산 변수(또는 bin으로 나눈 연속 변수)의 결합 **도수표** `counts`(shape `(A, B)`, 음이 아닌 정수)가 주어진다. `counts[a, b]`는 $X$가 $a$번째 값, $Y$가 $b$번째 값인 관측의 수다.

`plugin_mi(counts)`를 완성해, 상대도수 $\hat p(a, b) = \text{counts}[a, b] / N$을 확률로 보고 계산한 상호정보량을 nat 단위로 반환한다.

$$
\hat I = \sum_{a, b} \hat p(a, b)\log\frac{\hat p(a, b)}{\hat p(a)\,\hat p(b)}, \qquad \hat p(a) = \sum_b \hat p(a, b),\ \ \hat p(b) = \sum_a \hat p(a, b).
$$

도수가 0인 칸은 합에서 뺀다($0 \log 0 = 0$). 결과에 `nan`이 나오면 안 된다.

테스트는 다음을 확인한다.

- 독립인 결합분포의 정확한 도수표(예: 바깥곱)에서는 0이다.
- $Y$가 $X$의 함수인 표에서는 $H(Y)$와 같다.
- 0 이상이고, 행과 열을 바꿔도(전치) 같다.
- **편향**: 독립인 두 변수에서 표본 100개를 뽑아 $10 \times 10$ 표를 만들면, 추정값의 평균이 0보다 뚜렷하게 크다. 근사 편향 $(A-1)(B-1)/(2N)$과 같은 자릿수인지 확인한다.

힌트: $\hat I = H(X) + H(Y) - H(X, Y)$로 계산해도 되고, 정의식으로 계산해도 된다.
