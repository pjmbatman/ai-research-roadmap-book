# CC-CV 충전 시간

내부 저항 하나로 근사한 셀을 생각한다. 개방 전압이 SOC의 1차 함수 $\mathrm{OCV}(s) = a + b\,s$이고, 충전 전류 $I > 0$에서 단자 전압은 $V = a + b\,s + I R$이다. SOC는 $ds/dt = I / (3600\,Q)$로 늘어난다($Q$는 Ah 단위 용량, $t$는 초).

CC-CV 충전은 두 단계다.

1. **CC**: 전류 $I_{\text{cc}}$로 충전하다가 단자 전압이 $V_{\max}$에 닿으면 멈춘다.
2. **CV**: 단자 전압을 $V_{\max}$로 유지한다. 그러면 전류가 저절로 줄어든다. 전류가 $I_{\text{cut}}$까지 줄면 충전을 끝낸다.

함수 `cc_cv_time(i_cc_a, q_ah, r_ohm, ocv_a_v, ocv_b_v, v_max_v, soc0, i_cut_a)`를 완성해 `(t_cc_s, t_cv_s)`, 즉 두 단계의 시간(초)을 반환한다.

- 시작 SOC `soc0`에서 이미 $a + b\,s_0 + I_{\text{cc}}R \ge V_{\max}$이면 CC 단계는 0초이고, CV가 전류 $(V_{\max} - a - b\,s_0)/R$에서 시작한다.
- CV를 시작하는 전류가 이미 $I_{\text{cut}}$ 이하이면 CV 단계도 0초다.

테스트는 닫힌 해와 1% 안에서 같은지 확인한다. 닫힌 해를 유도해도 되고, 작은 시간 간격으로 적분해도 된다.
