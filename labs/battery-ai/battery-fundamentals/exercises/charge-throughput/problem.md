# 측정 기록에서 용량·에너지·EFC 계산하기

사이클러가 남긴 기록은 시각 `time_s`, 전류 `current_a`, 단자 전압 `voltage_v`의 세 배열이다. 이 기록에서 방전·충전 전하량과 방전 에너지, 등가 완전 사이클(EFC)을 계산하는 함수 `throughput(time_s, current_a, voltage_v, q_nom_ah, discharge_sign=+1)`을 완성한다.

| 인자 | 설명 |
|---|---|
| `time_s` | `(T,)` 시각 [s]. 증가하지만 간격은 일정하지 않을 수 있다 |
| `current_a` | `(T,)` 전류 [A]. 부호 규약은 `discharge_sign`이 정한다 |
| `voltage_v` | `(T,)` 단자 전압 [V] |
| `q_nom_ah` | 공칭 용량 [Ah] |
| `discharge_sign` | 방전 전류가 양수로 기록되었으면 `+1`, 음수로 기록되었으면 `-1` |

반환은 네 값의 dict다.

- `"discharge_ah"`: 방전 방향으로 흐른 전하량 [Ah] (0 이상)
- `"charge_ah"`: 충전 방향으로 흐른 전하량 [Ah] (0 이상)
- `"discharge_wh"`: 방전 중 셀이 내보낸 에너지 [Wh] (0 이상)
- `"efc"`: `discharge_ah / q_nom_ah`

**적분 규칙.** 측정 $k$의 전류와 전압이 다음 측정 시각까지 유지된다고 본다(영차 유지). 즉 구간 $[t_k, t_{k+1})$의 기여는 $I_k (t_{k+1} - t_k)$이고, 마지막 측정은 기여하지 않는다. 초를 시간으로 바꿀 때 3600으로 나누는 것을 잊지 않는다.

힌트: 먼저 전류를 "방전 +" 규약으로 바꾼 뒤, 양수 부분과 음수 부분을 따로 적분한다.
