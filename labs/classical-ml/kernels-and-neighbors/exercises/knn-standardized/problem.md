# 표준화를 포함한 kNN 회귀

함수 `knn_predict(X_train, y_train, X_test, k)`를 완성해, 시험 입력마다 kNN 회귀 예측을 담은 shape `(M,)` 배열을 반환한다.

1. **학습 데이터의** 특징별 평균 $\mu_j$와 표준편차 $s_j$(`ddof=0`)로 학습 입력과 시험 입력을 **모두** 표준화한다. 시험 데이터의 통계량을 쓰면 누수다.
2. 표준화된 공간에서 시험 점마다 모든 학습 점까지의 Euclid 거리를 계산한다.
3. 가장 가까운 학습 점 $k$개의 `y_train` 평균을 예측으로 쓴다.

| 인자 | shape |
|---|---|
| `X_train` | `(N, p)` |
| `y_train` | `(N,)` |
| `X_test` | `(M, p)` |

힌트: 거리 행렬은 브로드캐스팅으로 `(M, N)` 배열 하나로 만들 수 있다. 가장 작은 $k$개의 인덱스는 `np.argsort`나 `np.argpartition`으로 찾는다.

테스트는 다음을 확인한다.

- `k = 1`이면 학습 입력에서의 예측이 학습 출력과 같다.
- `k = N`이면 모든 예측이 `y_train`의 평균이다.
- 한 특징의 단위를 1000배 바꿔도 예측이 같다(표준화했으므로).
- 숫자가 큰 무관한 특징이 있어도 표준화 덕분에 중요한 특징을 쓴다.
- 직접 계산한 작은 예와 같다.
