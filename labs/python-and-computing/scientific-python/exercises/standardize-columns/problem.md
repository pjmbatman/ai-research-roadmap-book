# 원본을 바꾸지 않는 열별 표준화

측정값 행렬 $\mathbf{X} \in \mathbb{R}^{N \times D}$의 각 열(특성)을 평균 0, 표준편차 1로 바꾸는 함수 `standardize(X)`를 완성한다.

$$
Z_{ij} = \frac{X_{ij} - \mu_j}{\sigma_j}, \qquad \mu_j = \frac{1}{N}\sum_i X_{ij}, \qquad \sigma_j = \sqrt{\frac{1}{N}\sum_i (X_{ij} - \mu_j)^2}
$$

함수는 `(Z, mu, sigma)`를 반환한다. 학습 데이터에서 구한 `mu`, `sigma`를 나중에 시험 데이터에 그대로 적용하기 위해서다(15.4장).

| 반환 | shape |
|---|---|
| `Z` | `(N, D)` |
| `mu` | `(D,)` |
| `sigma` | `(D,)` |

이 장의 함정을 모두 피해야 테스트를 통과한다.

- **axis.** 열마다의 통계량은 행 방향(`axis=0`)으로 줄여서 구한다.
- **broadcasting.** `(N, D)`에서 `(D,)`를 빼면 각 행에서 같은 벡터를 뺀다. `(N,)`짜리를 빼려 하면 오류가 나거나(`N != D`) 조용히 틀린다(`N == D`).
- **원본 보존.** `X -= mu`처럼 제자리 연산을 쓰면 호출한 쪽의 데이터가 바뀐다. 입력은 바뀌면 안 된다.
- **정수 입력.** 정수 배열이 들어와도 결과는 실수여야 한다. 정수 배열에 제자리 연산으로 실수를 넣으면 잘린다.
- **상수 열.** 모든 값이 같은 열은 $\sigma_j = 0$이다. 0으로 나누지 말고 그 열의 `sigma`를 1로 바꾸어 `Z`의 해당 열이 0이 되게 한다.
