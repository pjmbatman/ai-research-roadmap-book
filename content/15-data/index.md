# 데이터 설계·처리·품질 관리

데이터의 의미와 저장 형식, 전처리와 탐색적 분석, 분할과 누수 방지, 버전·문서화, 합성·시뮬레이션 데이터를 다룬다.

## 왜 이 부가 필요한가

모델은 데이터가 허락하는 만큼만 배운다. 잘못된 분할 하나가 논문 전체의 결론을 무효로 만든다.
