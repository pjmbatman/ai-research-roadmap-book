# 분포 기반 문제 정의

## 학습 목표

- 문제에 필요한 분포가 무엇인지 정한다
- 점 예측을 분포에 대한 의사결정으로 이해한다
- 분포를 출력하는 모델을 설계한다

## 무엇의 분포가 필요한가

- **핵심 메시지:** 같은 데이터로도 질문에 따라 필요한 분포가 다르다. 먼저 "무엇의 분포를 알고 싶은가"를 정해야 모델과 손실이 정해진다.
- **설명 순서:** 왜(점 예측 하나로는 언제 틀리는지 알 수 없다) / 정의($p(x, y)$, $p(y \mid x)$, $p(x)$, $p(z \mid x)$, $p(\theta \mid \mathcal{D})$) / 표: 연구 질문 → 필요한 분포 / 세 출력의 구분: 점 예측 $\hat{y} = f_\theta(x)$, 조건부 예측분포 $p_\theta(y \mid x)$, 파라미터 사후분포 $p(\theta \mid \mathcal{D})$
- **예제:** 실 1 진동자의 잡음 섞인 위치 측정. "다음 측정값은?" → $p(y \mid t)$, "감쇠비는 얼마인가?" → $p(\zeta \mid \mathcal{D})$(13장 예고), "그럴듯한 궤적을 만들어라" → $p(\mathbf{x})$(19장 예고)
- **시각화·위젯:** 질문 → 분포 대응표
- **코드:** 없음
- **예측 퀴즈:** `distribution-statements`
- **흔한 오개념:** 모든 문제를 $y = f(x)$ 회귀로 보는 것
- **참고:** Murphy, *Probabilistic Machine Learning: An Introduction* 4–5장 — 서지 확인 후 등록

## 결정 이론

- **핵심 메시지:** 점 예측은 분포에 대한 의사결정이다. 손실을 고르면 최적의 대표값이 정해진다: 제곱손실 → 조건부 평균, 절댓값손실 → 조건부 중앙값, pinball loss → 분위수.
- **설명 순서:** 정의(기대 손실 최소화) / 수식(제곱손실의 한 줄 유도, 중앙값·분위수는 유도 스케치) / 직관(분포 모양을 바꾸며 세 대표값이 갈라지는 모습) / 연구에서의 의미(MSE로 학습한 모델이 무엇을 추정하는지)
- **예제:** 비대칭 잡음(오른쪽 꼬리)이 있는 측정에서 평균·중앙값·90% 분위수의 차이, 쌍봉 분포에서 평균이 실제로 드문 값이 되는 경우
- **시각화·위젯:** `loss-to-estimator`(분포 모양: 대칭·비대칭·쌍봉, τ 슬라이더)
- **코드:** `exec="browser"` — 표본에서 세 손실을 격자 탐색으로 최소화해 평균·중앙값·분위수와 일치함을 확인
- **예측 퀴즈:** `squared-loss-optimum`, `absolute-loss-optimum`, `bimodal-mean`
- **흔한 오개념:** 다봉 분포에서 조건부 평균을 대표값으로 쓰는 것
- **참고:** 위와 같음

## 분포를 출력하는 모델

- **핵심 메시지:** 모델의 출력을 점이 아니라 분포의 파라미터로 바꾸면, 손실은 그 분포의 음의 로그우도가 된다.
- **설명 순서:** 이분산 가우시안 회귀(평균·분산 head, NLL 손실, 분산은 softplus 등으로 양수 보장) / 분위수 회귀(τ별 head와 pinball loss, 분위수 교차 문제) / mixture density network(다봉) / 연구에서의 의미(측정 잡음이 조건마다 다를 때)
- **예제:** 진폭이 클수록 센서 잡음이 커지는 진동자 측정(이분산 합성 데이터)
- **시각화·위젯:** 평균 ± 2σ 띠와 분위수 곡선을 겹친 그림
- **코드:** `exec="browser"` — NumPy로 이분산 선형 모델을 NLL 경사하강으로 학습, 분위수 회귀와 띠 비교
- **예측 퀴즈:** `pinball-quantile`(슬라이더 응답)
- **흔한 오개념:** 분산 head가 0으로 수렴해 NLL이 발산하는 학습 불안정을 모델 탓으로 돌리는 것
- **참고:** Murphy 입문 11장(회귀) — 서지 확인 후 등록

## 적정 점수 규칙

- **핵심 메시지:** 예측분포는 적정 점수 규칙(proper scoring rule)으로 평가한다. 적정 규칙은 참 분포를 그대로 보고할 때 기대 점수가 가장 좋다.
- **설명 순서:** 정의 / NLL과 CRPS(가우시안 CRPS의 닫힌 형태) / 직관(과신·과소신 예측분포가 받는 점수) / 21.2장(예측분포 평가)으로 연결
- **예제:** 같은 평균에 분산만 다른 세 예측분포의 NLL·CRPS 비교
- **시각화·위젯:** 세 예측분포와 관측값, 점수 막대
- **코드:** `exec="browser"` — 가우시안 NLL과 CRPS 계산
- **예측 퀴즈:** 추가: 과신한 예측분포의 NLL
- **흔한 오개념:** 점 예측 지표(RMSE)만으로 예측분포를 평가하는 것
- **참고:** Gneiting·Raftery, "Strictly Proper Scoring Rules, Prediction, and Estimation"(2007) — 원문 확인 후 등록

## 불확실성의 출처 구분

- **핵심 메시지:** 불확실성은 관측 잡음(데이터가 늘어도 줄지 않음), 파라미터 불확실성(데이터가 늘면 줄어듦), 모델 구조 불확실성(모델이 틀림)으로 나뉜다. 출처에 따라 대응이 다르다.
- **설명 순서:** 세 출처의 정의 / 예측분포에서 어떻게 섞이는가 / 13장(베이지안)과 21.1장(불확실성 정량화)으로 연결
- **예제:** 진동자 — 센서 잡음, 짧은 관측으로 인한 감쇠비 추정의 불확실성, 실제로는 비선형 감쇠인데 선형 모델을 쓴 경우
- **시각화·위젯:** 세 출처를 나눈 도식
- **코드:** 없음
- **예측 퀴즈:** 추가: 데이터를 늘려도 줄지 않는 불확실성
- **흔한 오개념:** 예측 구간과 신뢰 구간을 혼동하는 것
- **참고:** 위와 같음

## 실습

- 같은 데이터에 MSE 회귀·이분산 가우시안 회귀·분위수 회귀를 학습하고 출력이 무엇을 의미하는지 비교한다.
- 연습문제(자동 채점): `pinball-loss` — pinball loss와 그 최소화로 분위수 추정, `gaussian-nll` — 이분산 가우시안 NLL

## 실패 사례

- 다봉 분포에서 조건부 평균을 대표값으로 쓰는 것
- 예측 구간과 신뢰 구간을 혼동하는 것
- 점 예측 지표만으로 예측분포를 평가하는 것

## 통과 기준

- 자신의 연구 문제를 '어떤 분포를 학습하고 어떤 결정에 쓰는가'로 다시 쓴다.
- 연습문제 두 개의 테스트를 통과한다.
