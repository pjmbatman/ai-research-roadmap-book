# 선형 모델과 정규화

## 학습 목표

- 선형·로지스틱 회귀와 정규화를 사용한다
- 정규화를 기하·확률적으로 해석한다

## 선형회귀

- 최소제곱, 특징 변환과 basis 확장

## 정규화

- Ridge · Lasso · Elastic net, 정규화 경로, 사전분포로서의 해석

## 로지스틱 회귀

- 확률 출력, 결정 경계, threshold

## 특징 공학

- 다항 · 상호작용 · 스플라인 특징

## 실습

- Ridge·Lasso의 정규화 경로를 그리고 계수 선택 결과를 해석한다.

## 실패 사례

- 표준화 없이 정규화를 적용하는 것

## 통과 기준

- 정규화 강도를 교차검증으로 고르고 계수를 해석한다.
