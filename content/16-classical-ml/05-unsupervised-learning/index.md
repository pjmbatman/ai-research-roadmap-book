# 비지도학습과 표현 탐색

## 학습 목표

- 차원 축소·군집·밀도추정·이상탐지를 사용한다
- 시각화 방법의 해석 한계를 안다

## 차원 축소

- PCA · kernel PCA · ICA

## 군집

- k-means · GMM · 계층적 군집 · DBSCAN, 거리와 스케일의 영향

## 밀도 추정과 이상 탐지

- KDE · isolation forest · one-class 방법, 재구성 오차 기반 탐지

## 시각화

- t-SNE · UMAP의 하이퍼파라미터와 해석 범위

## 군집의 의미

- 통계적 군집과 실제 물리적 집단의 구분

## 실습

- 시각적으로 분리된 UMAP embedding이 실제 하위 과제의 일반화 성능과 연결되는지 검증한다.

## 실패 사례

- t-SNE의 군집 간 거리와 크기를 해석하는 것

## 통과 기준

- 비지도 분석 결과를 독립적인 검증으로 확인한다.
