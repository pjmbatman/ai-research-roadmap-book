# Git·협업·AI 에이전트

Git과 GitHub로 변경을 추적·협업하고, AI 코딩 도구와 에이전트를 검증 가능한 개발 과정에 통합한다.

## 왜 이 부가 필요한가

코드 이력은 실험 결과의 근거다. AI 에이전트는 생산성을 크게 높이지만, 지침·도구·검증 체계 없이 쓰면 연구 결론을 오염시킨다.
