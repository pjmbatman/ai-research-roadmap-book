# Scientific Machine Learning

물리 모델과 학습 문제의 대응, PINN, Neural ODE와 미분가능 시뮬레이션, neural operator, 하이브리드·대리모델, 시스템 식별과 상태 추정, 역문제와 불확실성 정량화, 대칭성을 반영한 모델을 다룬다.

## 왜 이 부가 필요한가

공학 연구에서 데이터는 비싸고 물리 법칙은 이미 알려져 있다. 물리와 학습을 결합하면 적은 데이터로 더 믿을 수 있는 모델을 만들 수 있지만, 결합 방식마다 고유한 실패가 있다.
