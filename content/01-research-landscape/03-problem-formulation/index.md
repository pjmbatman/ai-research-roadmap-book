# 문제를 수학적으로 정의하기

## 학습 목표

- 입력·출력·상태·파라미터·잠재변수를 구분한다
- 추론 시점에 이용 가능한 정보를 명시한다
- 문제 유형을 분류한다

## 변수의 역할

- 입력 x, 출력 y, 제어입력 u, 파라미터 θ, 잠재변수 z, 상태 s
- 관측 가능한 변수와 숨겨진 상태, 직접 측정값과 추정된 label

## 문제의 유형

- 정적 예측 · 시계열 예측 · 상태 추정 · 역문제 · 최적화 · 제어 · 생성

## 정보의 시점

- 학습 시점과 추론 시점에 이용 가능한 정보
- 미래 정보 사용 여부, 인과적(causal) 입력 구성

## 범위의 명시

- 예측 구간(horizon), 공간 범위, 시간 해상도, 일반화 대상(새 샘플·새 셀·새 조건·새 장비)

## 문제 정의 문서

- 입력·정답 정의·평가 단위·성공 기준을 담은 한 장짜리 명세

## 실습

- '배터리 SOH 추정'을 입력 구간·정답 정의·대상 셀·미래 정보 사용 여부·일반화 대상까지 포함한 명세로 작성한다.

## 실패 사례

- 추론 시점에 존재하지 않는 정보를 입력에 넣는 것
- 일반화 대상을 정하지 않은 채 random split을 쓰는 것

## 통과 기준

- 자신의 연구 문제를 한 장짜리 명세로 쓰고 동료가 같은 실험을 설계할 수 있다.
