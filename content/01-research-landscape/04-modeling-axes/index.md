# 모델링을 나누는 여러 축

## 학습 목표

- 학습 패러다임·판별/생성·점/분포·빈도/베이지안 축을 구분한다
- 이 축들이 서로 독립적임을 설명한다

## 학습 신호에 따른 구분

- 지도 · 비지도 · 자기지도 · 준지도 · 강화학습

## 판별 모델과 생성 모델

- 조건부분포 p(y|x), 결합분포 p(x,y), 데이터 분포 p(x)
- 데이터 생성 과정을 가정한다는 것의 의미

## 점 예측과 분포 예측

- f(x)를 출력하는 모델과 p(y|x)를 출력하는 모델

## 결정론적 모델과 확률적 모델, 빈도주의와 베이지안

- 파라미터를 고정된 미지수로 보는 관점과 확률변수로 보는 관점

## 학습 구성 방식

- end-to-end · 단계별 학습 · 사전학습 후 미세조정 · 물리-데이터 하이브리드

## 축들은 독립적이다

- 판별 모델도 예측분포를 출력할 수 있고, 생성 모델도 베이지안 추론 없이 학습할 수 있다

## 실습

- 서로 다른 논문 다섯 편을 각 축에 따라 분류한 표를 만든다.

## 실패 사례

- '생성 모델 = 베이지안', '판별 모델 = 점 예측'처럼 축을 섞는 것

## 통과 기준

- 임의의 모델을 각 축 위에 위치시키고 그 근거를 말한다.
