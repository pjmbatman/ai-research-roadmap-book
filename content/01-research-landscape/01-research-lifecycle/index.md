# AI 연구의 생애주기

## 학습 목표

- 연구의 전체 단계를 설명한다
- 각 단계에서 내려지는 결정과 가정을 식별한다

## 문제에서 후속 연구까지

- 현실의 문제 → 연구 질문 → 수학적 정의 → 데이터 → 모델 → 학습 → 평가 → 해석 → 후속 연구
- 각 단계의 산출물과 되돌아가는 지점(feedback loop)

## 연구의 종류

- 알고리즘 연구 · 응용 연구 · 시스템 연구 · 데이터·벤치마크 연구 · 분석 연구
- 벤치마크 성능 개선과 현실 문제 해결의 관계

## 학습과 추론, 오프라인과 운영

- 학습 단계와 추론 단계의 차이
- 오프라인 평가와 실제 운영 환경의 간극

## 제약과 절충

- 정확도 · 계산량 · 데이터 비용 · 신뢰성 · 해석 가능성 사이의 trade-off

## 실습

- 관심 논문 하나를 생애주기의 각 단계로 분해하고, 단계별 가정을 한 장에 정리한다.

## 실패 사례

- 모델 단계만 연구라고 생각하는 것
- 평가 단계를 마지막에 설계하는 것

## 통과 기준

- 논문 하나를 생애주기로 분해한 문서를 작성하고 각 단계의 가정을 말한다.
