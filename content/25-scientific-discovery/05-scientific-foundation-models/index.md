# 과학 Foundation Model과 AI 에이전트

## 학습 목표

- 과학 분야의 사전학습 모델이 무엇을 전이하는지 평가한다
- LLM 에이전트를 과학 연구 과정에 쓰는 범위와 위험을 안다

## 과학 foundation model

- 분자·단백질·기상·물질 데이터의 사전학습, 무엇이 전이되는가

## 평가

- 미사용 분포·과제에서의 전이, 데이터 중복과 누수

## LLM과 과학 문헌

- 문헌 검색·요약·지식 추출, 환각과 인용 검증

## 과학 연구 에이전트

- 도구 사용(시뮬레이터·데이터베이스·코드 실행), 계획과 검증, 사람의 승인 지점

## 위험과 책임

- 검증되지 않은 결론, 재현성, 이중 용도 위험

## 실습

- 공개 과학 사전학습 모델 하나를 작은 하위 과제로 전이해 무작위 초기화·단순 baseline과 비교한다.

## 실패 사례

- 모델 크기만으로 전이 효과를 가정하는 것
- 에이전트가 낸 결과를 검증 없이 보고하는 것

## 통과 기준

- 사전학습 모델의 전이 효과와 한계를 통제된 비교로 보고한다.
