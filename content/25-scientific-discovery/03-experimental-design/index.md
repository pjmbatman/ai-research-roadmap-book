# 능동 학습과 베이지안 실험 설계

## 학습 목표

- 다음 실험·시뮬레이션을 고르는 기준을 설계한다
- 정보 이득 기반 실험 설계를 이해한다

## 왜 실험을 고르는가

- 실험·시뮬레이션 비용, 예산 제약

## 능동 학습

- 불확실성 샘플링 · 다양성 · 기대 모델 변화, batch 선택

## 베이지안 실험 설계

- 기대 정보 이득, 파라미터 추정을 위한 설계

## 베이지안 최적화와의 관계

- 최적값 찾기와 모델 학습하기의 차이

## 평가

- 같은 예산에서 무작위 선택 대비 효율, 결과 재현

## 실습

- 비싼 함수(시뮬레이터)를 대상으로 능동 학습과 무작위 선택의 학습 곡선을 같은 예산에서 비교한다.

## 실패 사례

- 초기 데이터가 너무 적은 상태에서 불확실성 추정을 믿는 것

## 통과 기준

- 실험 선택 전략의 효율을 같은 예산의 대조군과 비교해 보인다.
