# 방정식 발견과 기호 회귀

## 학습 목표

- 데이터에서 지배 방정식을 찾는 방법을 이해한다
- 발견된 식의 타당성을 검증한다

## 희소 회귀로 동역학 찾기

- 후보 함수 사전과 희소 회귀(SINDy 계열), 미분 추정의 잡음 문제

## 기호 회귀

- 식의 탐색 공간, 유전 프로그래밍과 신경망 기반 방법

## 해석 가능성과 단순성

- 정확도와 식 복잡도의 trade-off, Pareto front

## 검증

- 외삽, 보존 법칙, 단위 일관성, 새 조건에서의 예측

## 실습

- 알려진 동역학 시스템의 잡음 섞인 궤적에서 지배 방정식을 복원하고, 잡음 수준에 따른 실패를 확인한다.

## 실패 사례

- 학습 구간에 잘 맞는 복잡한 식을 법칙으로 주장하는 것
- 단위가 맞지 않는 식을 받아들이는 것

## 통과 기준

- 발견한 식을 외삽·단위·보존 법칙으로 검증한 보고서를 쓴다.
