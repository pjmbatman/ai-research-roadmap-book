# 최적화 문제의 구조

## 학습 목표

- 목적함수·제약·feasible set을 정의한다
- 볼록성을 판별한다
- 최적성 조건을 사용한다

## 문제의 구성

- 목적함수 · 결정변수 · 제약조건 · feasible set

## 볼록성

- convex set · convex function · strong convexity, 판별 방법

## 최적해의 종류

- 국소·전역 최적, stationary point, saddle point

## 최적성 조건

- 1차·2차 조건, Hessian과 곡률

## 실습

- 여러 손실함수의 볼록성을 Hessian으로 판별하고 등고선과 함께 시각화한다.

## 실패 사례

- gradient가 0이면 최솟값이라고 단정하는 것

## 통과 기준

- 주어진 문제를 표준형으로 쓰고 볼록 여부와 최적성 조건을 말한다.
