# Linux·서버·원격 개발

연구 서버를 안정적으로 다루기 위한 Linux, 자원 모니터링, SSH, 원격·클라우드 실행 구조를 익힌다.

## 왜 이 부가 필요한가

연구의 대부분은 원격 GPU 서버에서 일어난다. 연결이 끊겨도 실험이 살아 있고, 자원 문제를 스스로 진단할 수 있어야 연구가 지속된다.
