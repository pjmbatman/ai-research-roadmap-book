# 실행 위치의 지도: 로컬·원격·클라우드

## 학습 목표

- 코드·연산·데이터·인증·세션의 위치를 구분한다
- 작업에 맞는 실행 구조를 선택한다

## 다섯 가지 질문

- 코드는 어디에 있는가 · 연산은 어디서 실행되는가 · 데이터는 어디에 있는가 · 누구의 자격으로 접근하는가 · 무엇이 세션을 유지하는가

## 대표적인 실행 구조

- 로컬 편집 · 로컬 실행
- 로컬 편집 · SSH 원격 실행
- 원격 서버에서 실행되는 에이전트 세션을 다른 기기에서 원격 제어(remote control)
- 클라우드 개발환경 · 클라우드 에이전트 · 관리형 notebook · 학습 job

## 비교 기준

- 비용, 데이터 이동량, 보안, 세션 지속성, 연결 제약

## SSH 접속과 원격 제어의 차이

- 터미널을 원격에 여는 것과 원격에서 돌아가는 세션을 조종하는 것

## 실습

- 자신이 쓰는 모든 도구(IDE, 노트북, 에이전트, 대시보드)에 대해 다섯 질문의 답을 표로 정리한다.

## 실패 사례

- 로컬 파일과 원격 파일을 혼동해 수정이 반영되지 않는 것
- 민감 데이터를 클라우드로 무심코 옮기는 것

## 통과 기준

- 임의의 작업에 대해 적절한 실행 구조를 고르고 그 이유를 다섯 질문으로 설명한다.
