# 화학·재료 데이터와 평가의 함정

## 학습 목표

- 화학·재료 데이터의 품질 문제를 진단한다
- 벤치마크 결과를 비판적으로 해석한다

## 데이터 품질

- 중복 구조, 측정 조건 차이, 계산 수준의 혼합

## 누수

- 유사 구조의 분할 간 공유, 사전학습 데이터 중복

## 벤치마크

- 포화된 벤치마크, 지표의 선택, 오차 막대

## 실제 활용과의 간극

- 후보 선별 성공률, 실험 검증

## 실습

- 공개 데이터셋 하나에서 중복·유사 구조를 탐지하고, 정제 전후의 벤치마크 성능 차이를 측정한다.

## 실패 사례

- 서로 다른 계산 수준의 데이터를 그대로 섞는 것

## 통과 기준

- 데이터 정제와 분할 근거를 포함한 평가 보고서를 쓴다.
