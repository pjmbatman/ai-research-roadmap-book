# 분자·재료 생성과 역설계

## 학습 목표

- 생성모델로 후보를 설계한다
- 생성 결과를 화학적 타당성과 유용성으로 평가한다

## 생성 방식

- 문자열 · 그래프 · 3차원 생성, 조건부 생성

## 최적화와 탐색

- 물성 예측 모델을 이용한 탐색, 베이지안 최적화

## 평가

- 유효성 · 고유성 · 신규성, 합성 가능성, 예측 모델 착취(exploitation)

## 실험 검증

- 후보 선별과 실험·계산 검증 루프

## 실습

- 생성모델로 만든 후보의 유효성·신규성과 물성 예측값을 평가하고, 예측 모델의 적용 영역 밖 후보 비율을 측정한다.

## 실패 사례

- 물성 예측 모델의 오차를 이용한 후보를 우수 후보로 보고하는 것

## 통과 기준

- 생성 후보를 타당성·신규성·적용 영역·검증 결과로 보고한다.
