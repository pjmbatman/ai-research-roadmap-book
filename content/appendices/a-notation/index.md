# 표기법

## 학습 목표

- 책 전체의 수학·코드 표기 규칙을 한곳에서 확인한다

## 수학 표기

- 스칼라 · 벡터 · 행렬 · 텐서 · 집합 · 확률변수 · 분포 · 기댓값

## 학습 문제 표기

- 데이터셋 D, 입력 x, 출력 y, 파라미터 θ, 잠재변수 z, 손실 L

## 미분 표기

- gradient · Jacobian · Hessian의 layout 규약

## 코드 표기

- shape 주석 규칙(B · T · C · D 등), 단위 접미사
