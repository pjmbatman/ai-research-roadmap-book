# 실패 사례 갤러리

## 학습 목표

- 책 전체의 실패 사례를 유형별로 찾아본다

## 데이터

- 누수 · 잘못된 분할 · 단위 오류

## 학습

- gradient 누적 · eval 모드 누락 · 수치 불안정

## 평가

- metric 집계 오류 · test set 오염 · 단일 seed 주장

## 환경

- 버전 충돌 · 비결정성

## 연구

- 과장된 주장 · 불공정 비교
