# 공통 자산

## 학습 목표

- 연구실 공통 자산을 구축하고 관리한다

## 공통 프로젝트 템플릿

- 설치 · 설정 · 학습 · 평가 · checkpoint · logging

## 공통 데이터셋

- 작지만 현실적인 교육용 데이터셋

## 수학–코드 대응 실습

- 최소제곱 · MLE · 역전파 · calibration · ODE

## 실패 사례 모음

- 잘못된 분할 · eval 모드 누락 · metric 집계 오류 · checkpoint 복원 실패

## 양식

- 재현 보고서 · 실험 계획서 · 연구 질문 문서

## 에이전트 지침과 skill

- 연구실 공통 AGENTS.md · SKILL.md

## 실습

- 공통 프로젝트 템플릿과 실패 사례 모음의 첫 버전을 만든다.

## 실패 사례

- 템플릿이 실제 프로젝트와 멀어지는 것

## 통과 기준

- 두 개 이상의 프로젝트가 공통 템플릿에서 시작한다.
