# 지식 관리와 인수인계

## 학습 목표

- 연구 지식이 사람과 함께 사라지지 않게 한다

## 지식의 종류

- 코드 · 데이터 · 실험 기록 · 암묵지

## 저장소

- 위키 · 저장소 docs · 연구 노트 · 에이전트 지침

## 인수인계

- 졸업·이동 시 체크리스트, 재현 가능한 상태로 넘기기

## 검색 가능성

- 명명 규칙 · 색인 · 태그

## 실습

- 졸업 예정 연구원의 프로젝트를 인수인계 체크리스트로 정리하고 다른 사람이 재현한다.

## 실패 사례

- 개인 컴퓨터에만 있는 데이터와 코드

## 통과 기준

- 인계받은 사람이 인계 문서만으로 주요 결과를 재현한다.
