# 단계별 리뷰 체계

## 학습 목표

- 연구 단계별 리뷰를 운영한다
- 연구 결론을 바꿀 수 있는 문제를 우선 검토한다

## 리뷰 단계

- 문제 정의 → 데이터(schema · 분할 · 누수) → baseline(pipeline) → 제안 방법(code · math) → 주요 주장(experiment) → 제출 전(재현성 · 주장)

## 체크리스트

- 단계별 필수 확인 항목

## 운영 원칙

- 형식보다 결론에 영향을 주는 문제 우선

## handoff

- 후속 연구자를 위한 인계 리뷰

## 실습

- 진행 중인 프로젝트 하나에 데이터·baseline 리뷰를 수행하고 결과를 기록한다.

## 실패 사례

- 제출 직전에만 리뷰하는 것

## 통과 기준

- 프로젝트가 각 단계 리뷰를 통과한 기록을 남긴다.
