# 오픈소스·데이터·벤치마크로 기여하기

## 학습 목표

- 과학 오픈소스 프로젝트에 기여한다
- 데이터셋과 벤치마크를 공개 가능한 형태로 만든다

## 오픈소스 기여

- 이슈 · PR · 리뷰 문화, 기여 가이드 읽기, 작은 기여부터

## 데이터셋 공개

- 데이터 카드, 라이선스, 저장소 선택, 영구 식별자

## 벤치마크 설계

- 과제 정의 · 분할 · 지표 · baseline · 리더보드의 함정

## 재현 패키지

- 코드 · 환경 · 데이터 · 실행 스크립트

## 이 로드맵에 기여하기

- 오탈자 · 실패 사례 · 퀴즈 · 위젯 · 도메인 장 기여 방법

## 실습

- 사용하는 과학 오픈소스 프로젝트에 문서·테스트·버그 수정 중 하나를 기여하거나, 이 로드맵에 실패 사례 하나를 기여한다.

## 실패 사례

- 라이선스와 이용 조건을 확인하지 않고 데이터를 재배포하는 것

## 통과 기준

- 병합된 기여 하나 또는 공개 가능한 데이터 카드·재현 패키지 하나를 만든다.
