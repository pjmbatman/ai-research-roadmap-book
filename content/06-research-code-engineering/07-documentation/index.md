# 연구 코드 문서화

## 학습 목표

- README로 설치부터 재현까지 안내한다
- docstring과 설계 문서를 작성한다

## README

- 목적 · 설치 · 데이터 준비 · 실행 · 결과 재현 · 인용

## docstring

- 인자 · 반환값 · shape · 단위 · 예외

## 설계 문서

- 데이터 설명서, 모델 설명, 실험 기록, 결정 기록(ADR)

## 변경 기록

- CHANGELOG, 결과에 영향을 준 변경 표시

## 실습

- 자신의 프로젝트 README를 처음 보는 사람이 그대로 따라 해 결과를 재현하게 만든다.

## 실패 사례

- 실행되지 않는 예제 명령
- 코드와 어긋난 문서

## 통과 기준

- 새 연구원이 구두 설명 없이 README만으로 첫 결과를 재현한다.
