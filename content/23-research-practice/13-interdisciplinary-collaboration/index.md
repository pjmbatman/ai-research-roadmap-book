# 도메인 과학자와의 협업

## 학습 목표

- 도메인 과학자와 문제 정의를 합의한다
- 서로 다른 분야의 평가 기준을 조율한다
- 협업의 산출물과 저자 기여를 정한다

## 공통 언어 만들기

- 용어 대응표, 서로의 '당연한 가정' 드러내기

## 문제 정의 합의

- 과학적으로 의미 있는 질문과 ML로 풀 수 있는 질문의 교집합

## 평가 기준의 조율

- ML 지표와 과학적 타당성(물리적 일관성·실험 검증)의 연결

## 데이터와 실험

- 실험 설계에 처음부터 참여하기, 데이터 생성 과정의 기록

## 협업의 운영

- 주기적 검토, 결과 공유 방식, 저자 기여와 발표 경로

## 실습

- 도메인 과학자(또는 그 역할의 동료)와 한 시간 인터뷰를 하고, 합의한 문제 정의서와 평가 기준을 작성한다.

## 실패 사례

- 도메인 전문가를 데이터 제공자로만 대하는 것
- ML 지표 개선을 과학적 기여로 포장하는 것

## 통과 기준

- 양쪽이 서명할 수 있는 문제 정의서와 평가 기준 문서를 만든다.
