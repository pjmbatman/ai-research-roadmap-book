# 실험 설계

## 학습 목표

- 가설을 반증할 수 있는 실험을 설계한다
- 공정한 비교 조건을 만든다
- ablation과 민감도 분석을 설계한다

## 반증 가능한 실험

- 대조군, 통제 변수

## 실험의 종류

- 주 비교 · ablation · 민감도 · 강건성 · 스케일링 실험

## 공정성

- 파라미터 수 · 계산량 · 데이터 · 탐색 예산 맞추기

## 효과의 분리

- 구조 효과와 학습 recipe 효과

## 편향 통제

- 데이터·모델·설정 선택 편향, leakage audit, test set 사용 기록

## 실험 계획서

- 실행 전에 무엇을 측정하고 어떻게 판단할지 기록

## 실습

- 제안 방법에 대한 실험 계획서를 작성하고, 성공·실패 각각의 결론을 먼저 적는다.

## 실패 사례

- 결과를 본 뒤 평가 방식을 바꾸는 것
- 제안 방법에만 유리한 조건

## 통과 기준

- 동료 리뷰에서 공정성과 반증 가능성을 인정받은 실험 계획서를 만든다.
