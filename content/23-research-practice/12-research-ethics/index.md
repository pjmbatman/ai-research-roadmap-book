# 연구 윤리와 오픈 사이언스

## 학습 목표

- 연구 윤리의 기본 원칙을 지킨다
- 코드·데이터를 공개 가능한 수준으로 정리한다

## 연구 무결성

- 위조 · 변조 · 표절, 결과 선택 보고의 문제

## 저자와 인용

- 저자 기여 기준, 인용 윤리

## 데이터와 라이선스

- 데이터 이용 조건, 소프트웨어 라이선스 선택

## AI 도구 사용

- 사용 기록과 공개 정책

## 오픈 사이언스

- 코드 · 데이터 · 모델 공개, artifact 문서화, 재현 패키지

## 실습

- 자신의 프로젝트를 공개 가능한 재현 패키지(README · 라이선스 · 데이터 안내 · 실행 스크립트)로 정리한다.

## 실패 사례

- 좋은 결과만 골라 보고하는 것
- 라이선스 없이 코드를 공개하는 것

## 통과 기준

- 연구 윤리 체크리스트를 통과한 재현 패키지를 만든다.
