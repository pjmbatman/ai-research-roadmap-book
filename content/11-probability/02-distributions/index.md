# 주요 분포와 지수족

## 학습 목표

- 주요 분포의 생성 이야기와 성질을 안다
- 지수족의 구조를 이해한다

## 이산 분포

- Bernoulli · binomial · categorical · Poisson · geometric

## 연속 분포

- uniform · Gaussian · exponential · gamma · beta · Student-t · log-normal · Laplace

## 분포의 생성 이야기

- 각 분포가 등장하는 상황과 모델링 가정

## 지수족

- 충분통계량, 자연 파라미터, log-partition, 켤레성과의 연결

## 혼합분포와 두꺼운 꼬리

- mixture, heavy tail과 이상치

## 실습

- 실제 데이터(예: 측정 잡음, 고장 간격)에 여러 분포를 적합하고 적합도를 비교한다.

## 실패 사례

- 모든 잡음을 가우시안으로 가정하는 것

## 통과 기준

- 주어진 데이터 생성 과정에 맞는 분포를 고르고 근거를 말한다.
