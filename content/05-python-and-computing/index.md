# Python과 계산 기초

수식을 정확하고 효율적인 코드로 옮기기 위한 Python 언어, 과학 계산 라이브러리, 계산 비용과 컴퓨터 구조를 익힌다.

## 왜 이 부가 필요한가

연구 코드의 버그는 대부분 언어와 라이브러리의 동작을 정확히 모르는 데서 시작한다. 성능 문제는 컴퓨터 구조를 모르면 진단할 수 없다.
