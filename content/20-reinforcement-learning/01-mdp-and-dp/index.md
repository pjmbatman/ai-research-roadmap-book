# MDP와 동적계획법

## 학습 목표

- MDP로 문제를 정의한다
- Bellman 방정식과 동적계획법을 이해한다

## MDP

- 상태 · 행동 · 전이 · 보상 · 할인, 정책

## 가치함수

- V와 Q, Bellman 방정식

## 동적계획법

- value iteration · policy iteration

## 부분 관측

- POMDP와 상태 추정

## 실습

- 작은 격자 환경에서 value iteration과 policy iteration을 구현한다.

## 실패 사례

- 보상 설계가 의도와 다른 행동을 유도하는 것

## 통과 기준

- 자신의 연구 문제를 MDP로 정의하고 상태·행동·보상의 선택을 정당화한다.
