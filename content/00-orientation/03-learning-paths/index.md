# 학습 경로

## 학습 목표

- 다섯 단계의 나선형 학습 순서를 이해한다
- 자신의 배경에 맞는 경로를 고른다

## 목차 순서와 학습 순서는 다르다

- 목차는 지식의 분류, 학습 경로는 훈련의 순서

## 다섯 단계 나선형 경로

- 1단계: 작은 연구 파이프라인을 완주한다 (작업대·데이터·baseline·PyTorch 기초)
- 2단계: 구현을 수학·통계로 설명한다 (선형대수·미분·확률·최적화)
- 3단계: 신뢰할 수 있는 연구 코드를 만든다 (설정·누수 방지·재현성·불확실성)
- 4단계: 기존 연구를 재현하고 확장한다 (아키텍처·논문 재현·ablation)
- 5단계: 독립 연구를 수행한다 (가설·공정 비교·논문·artifact)

## 배경별 경로

- 공학 전공 신입생 · 컴퓨터과학 전공 신입생 · 수학·통계 전공자 · 실험 위주 연구자

## 도메인 트랙

- A. 데이터 기반 예측·신뢰성 · B. 물리 모델·Scientific ML · C. 대규모 사전학습·Foundation Model

## 기간은 계획 범위, 진도는 산출물

- 1–2개월 · 3–6개월 · 6–12개월 · 12–24개월의 대표 산출물

## 실습

- 자신의 배경과 연구 주제에 맞춰 다음 3개월의 경로(장 목록과 산출물)를 작성한다.

## 실패 사례

- 기간을 진도의 기준으로 삼는 것
- 경로 없이 흥미 있는 장만 골라 읽는 것

## 통과 기준

- 3개월 경로와 각 단계의 산출물을 지도교수 또는 선배와 합의한다.
