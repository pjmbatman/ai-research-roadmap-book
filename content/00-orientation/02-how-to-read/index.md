# 이 책을 읽는 법

## 학습 목표

- 장의 공통 형식을 이해한다
- 난이도 등급과 트랙 표시를 읽는다
- 실습과 통과 기준을 사용하는 법을 안다

## 부·장·절의 구조와 트랙

- 7개 트랙: 시작하기 · 연구 작업대 · 수학적 기초 · 모델링 · 연구 실천 · 도메인 · 연구실
- 부(Part)는 주제, 장(Chapter)은 하나의 학습 단위, 절(Section)은 하나의 개념

## 모든 장의 공통 형식

- 학습 목표 · 선수 지식 · 핵심 개념 · 구현·실습 · 실패 사례 · 통과 기준
- 실패 사례를 본문만큼 중요하게 다루는 이유

## 난이도 등급

- 필수(core): 모든 연구원이 설명하고 직접 수행할 수 있어야 하는 내용
- 심화(advanced): 연구 주제에 따라 깊이 들어갈 내용
- 참조(reference): 필요할 때 문서를 읽고 적용할 수 있으면 되는 내용

## 표기법·용어·코드 규칙

- 수학 표기법(부록), 한·영 용어 병기 원칙, 코드 블록과 shape 주석 규칙
- 실습 코드 저장소(labs/)와 장의 대응

## 실습

- 관심 있는 장 하나를 골라 공통 형식의 각 항목이 무엇을 요구하는지 표로 정리한다.

## 실패 사례

- 통과 기준을 건너뛰고 다음 장으로 넘어가는 것
- 심화 장을 필수 장보다 먼저 파고드는 것

## 통과 기준

- 임의의 장을 펼쳤을 때 무엇을 읽고, 무엇을 만들고, 무엇으로 통과를 판단하는지 말한다.
