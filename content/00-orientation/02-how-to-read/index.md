# 이 책을 읽는 법

## 학습 목표

- 장의 공통 형식을 이해한다
- 레이어·트랙·난이도 표시를 읽는다
- 실습·퀴즈·통과 기준으로 자신의 진도를 확인한다

## 레이어·트랙·부·장

- 레이어 L0–L5: 입문 · 기반 · 핵심 · 확장 · 연구 · 조직, 각 트랙은 같거나 아래 레이어에만 기댄다
- 11개 트랙: ORI 오리엔테이션 · INF 연구 인프라 · RSE 연구 소프트웨어 공학 · MTH 수리 기초 · PSI 확률·통계적 추론 · MLC 머신러닝 핵심 · MLA 머신러닝 심화 · MLS 머신러닝 시스템 · RES 연구 방법론 · SCI 과학·공학 AI · LAB 연구실 운영 (+ REF 참고 자료)
- 트랙마다 핵심 질문 · 도달 목표 · 주된 평가 방식 · 졸업 과제
- 부(Part)는 주제, 장(Chapter)은 하나의 학습 단위, 절(Section)은 하나의 개념

## 모든 장의 공통 형식

- 학습 목표 · 선수 지식 · 핵심 개념 · 구현·실습 · 실패 사례 · 통과 기준
- 실패 사례를 본문만큼 중요하게 다루는 이유

## 이론과 실습을 한 화면에서

- 위젯: 직접 조작하며 개념을 관찰하고, 수식·코드와 같은 값을 공유한다
- 코드 셀: 브라우저 · CPU 서버 · GPU 서버에서 바로 실행, 실행 위치 배지 읽기
- 예측해 보기: 본문 중간의 퀴즈 한 문항에 먼저 답하고 결과로 확인하기

## 평가 방식

- 개념 퀴즈 · 코드 실습 · 터미널 실습 · 문서 산출물 · 동료·지도 리뷰
- 실습이 코드가 아닌 장(연구 방법론 등)은 퀴즈와 문서 산출물로 통과를 확인한다

## 난이도 등급

- 필수(core): 모든 연구원이 설명하고 직접 수행할 수 있어야 하는 내용
- 심화(advanced): 연구 주제에 따라 깊이 들어갈 내용
- 참조(reference): 필요할 때 문서를 읽고 적용할 수 있으면 되는 내용

## 표기법·용어·코드 규칙

- 수학 표기법(부록), 한·영 용어 병기 원칙, 코드 블록과 shape 주석 규칙
- 실습 코드 저장소(labs/)와 장의 대응

## 실습

- 관심 있는 장 하나를 골라 공통 형식의 각 항목이 무엇을 요구하는지 표로 정리한다.

## 실패 사례

- 통과 기준을 건너뛰고 다음 장으로 넘어가는 것
- 심화 장을 필수 장보다 먼저 파고드는 것

## 통과 기준

- 임의의 장을 펼쳤을 때 무엇을 읽고, 무엇을 만들고, 무엇으로 통과를 판단하는지 말한다.
