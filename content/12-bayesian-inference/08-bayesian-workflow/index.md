# 베이지안 워크플로

## 학습 목표

- 사전 예측 점검부터 모델 비교까지 베이지안 분석 절차를 수행한다

## 모델 구축

- 생성 이야기로 모델 쓰기, 확률 프로그래밍 도구(PyMC · NumPyro · Stan)

## 사전 예측 점검

- prior predictive check

## 사후 점검

- posterior predictive check, 사전 민감도 분석

## 모델 비교

- LOO-CV · WAIC, Bayes factor의 주의점

## 보고

- 사후 요약과 시각화

## 실습

- 실제 데이터에 대해 사전 예측 점검 → 적합 → 진단 → 사후 예측 점검 → 모델 개선의 한 사이클을 수행한다.

## 실패 사례

- 기본 사전을 검토 없이 사용하는 것

## 통과 기준

- 베이지안 분석 보고서를 워크플로 각 단계의 근거와 함께 작성한다.
