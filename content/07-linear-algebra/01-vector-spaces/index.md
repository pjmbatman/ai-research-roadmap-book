# 벡터공간과 선형사상

## 학습 목표

- 벡터공간의 공리와 예를 설명한다
- span·독립·basis·dimension을 정의한다
- 선형사상과 행렬 표현을 연결한다

## 집합·함수·벡터공간

- 벡터공간의 공리, 숫자 배열이 아닌 벡터의 예(함수, 다항식, 신호)
- 부분공간

## span·선형독립·basis·dimension

- 좌표와 basis 선택, 차원의 의미

## 선형사상

- 선형성의 정의, 합성, 핵(kernel)과 상(image)

## 행렬 표현

- basis에 따른 행렬 표현, 기저 변환(change of basis), 닮음

## 실습

- 같은 선형사상을 두 basis에서 행렬로 표현하고 기저 변환 공식으로 서로 변환되는지 확인한다.

## 실패 사례

- 벡터를 숫자 배열로만 생각하는 것
- 좌표와 벡터 자체를 혼동하는 것

## 통과 기준

- 함수공간의 예를 들어 벡터공간의 공리를 확인하고 미분 연산자의 행렬 표현을 만든다.
