# 대칭과 군 표현

## 학습 목표

- 대칭을 군으로 표현한다
- 불변성과 등변성을 수학적으로 정의한다
- 과학 데이터의 대칭을 모델 설계로 연결한다

## 대칭과 군

- 군의 정의, 회전·평행이동·반사·치환, 연속군과 이산군

## 군의 표현

- 군을 행렬로 표현하기, 회전 행렬 SO(3)·O(3), 치환 행렬

## 불변성과 등변성

- f(gx)=f(x)와 f(gx)=g·f(x), 스칼라·벡터·텐서 물리량의 변환 규칙

## 대칭을 모델에 넣는 방법

- 데이터 증강 · 불변 특징 · 등변 구조, 각 방법의 장단점

## 과학에서의 대칭

- 분자·결정·유체·장(field) 데이터의 대칭, 보존 법칙과 대칭(Noether 정리의 직관)

## 실습

- 2차원 점구름을 회전시키며 일반 MLP와 회전 불변 특징 기반 모델의 출력이 어떻게 달라지는지 측정한다.

## 실패 사례

- 증강만으로 대칭이 보장된다고 생각하는 것
- 벡터 물리량에 스칼라용 불변성을 적용하는 것

## 통과 기준

- 과학 데이터 하나의 대칭군을 쓰고, 예측 대상이 불변인지 등변인지 판별한다.
